# v45 — 빈 장중 차트의 일봉 이동과 404 원인 대조

공개 버전 `20261004-chart-recovery-v45`, 프런트 빌드 `faXMhw5ECQG4XOILocKMD`. 기존 v44 종목별 수집 순서·DB·사용자 관심·설정·주소를 유지했다.

## 원인 대조

2026-10-04 06:45:52 UTC 운영 DB 감사에서 404 작업 768건은 110종목이었다. KONEX 107, KOSPI 3이며 모두 당시 토스 종목 목록에 없었다. 목록 수집은 2026-10-03 07:57 UTC였고 세 시장 모두 정상 상태와 원본 근거가 있었다. 이는 해당 시점의 목록 대조이며 영구 미지원 판정이 아니다. 종목을 삭제하거나 404를 정상 빈 자료로 바꾸지 않았다.

110종목 모두 기존 네이버 일봉 저장 행이 있었다. 예: 태양3C(052960) 899행. 이 원천은 조정 방식 미확인·provider_window_only이므로 토스 통합 자료나 전체 상장기간 확보로 바꾸어 표시하지 않는다. 거래 수급·신용·대차의 404를 가격 자료 확보로 완료 처리하지 않는다.

이번 조사에서 0106J0·0120X0은 이름상 X클래스 펀드이며 보통주·우선주 범위와의 분류 검토가 필요하다. 아직 종목 목록과 저장 자료를 임의 삭제하지 않았다. 기본정보 및 공식 상품 근거를 별도로 대조할 항목이다.

## 실제 변경

`apps/web/components/market/market-pulse.tsx`의 빈 그래프 상태를 수정했다. loading/collecting/pending만 로딩, error/unavailable은 조회 실패, 그 외 빈 응답은 선택 기간 자료 없음으로 표시한다. 장중 선·영역 조회에 자료가 없으면 ‘일봉 차트 보기’를 제공한다. 5분봉 실패/빈 응답에도 일봉으로 이동할 수 있다. 로딩 중에는 실패 동작을 먼저 내놓지 않는다. 가격선·OHLC를 만들거나 다른 시장 시계열을 섞지 않는다.

## 남은 항목과 새 관찰

404 거래 자료·전 종목 전체 기간·TTM/분할·배당 기업행사·장중 수신·공개 성능은 미완료다. 이번에는 성능 개선을 측정하거나 100동시 목표 통과로 주장하지 않는다. 수정된 상태 안내가 자료 수집 완료를 뜻하지 않는다.

태양3C의 같은 화면에서 상단 기본정보 거래량 1과 마지막 일봉 거래량 0이 함께 관찰됐다. 출처별 기준일/범위/확정 여부 대조가 추가로 필요하며 한쪽을 임의로 0 또는 다른 값으로 덮어쓰지 않았다. 이 차이는 해결된 데이터 일관성으로 보고하지 않는다.
