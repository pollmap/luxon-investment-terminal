# v128 종목 작업 화면 — 구현·검증 기록

기준일: 2026-10-11 KST. 앱 소스 기준 문서이며, 공개 배포 판정은 같은 폴더의 배포 기록을 별도로 확인합니다.

## 구현한 동작

- 최초 종목 시세: **3개월·일봉·캔들**. 내부 `range=63`은 기존 `chartCutoff`의 달력 3개월 규칙을 사용합니다. 63개 거래봉으로 기간을 단정하지 않습니다.
- 공유 링크 → 종목별 저장값 → 최초 기본값 순서를 유지합니다. 저장값 복원 전에 기본 차트를 먼저 요청하는 경로를 제거했습니다.
- 이전 `period/kind`만 있는 장중 공유 링크도 계속 장중 화면으로 엽니다.
- ‘기본 차트로’는 시세 선택을 3개월·일봉·캔들로 복원하고 저장합니다. 관심종목·선택 탭·분석 설정을 지우지 않습니다.
- PC 1280px 이상: 왼쪽 종목 목록 240px, 중앙 가격 차트, 오른쪽 호가 280px입니다. 차트 높이는 420px입니다.
- 1024~1279px: 왼쪽 목록과 차트를 유지하고 호가·체결은 버튼으로 엽니다. 1024px 미만은 목록을 접어 본문을 확보합니다.
- 휴대폰: 차트 높이 320px, 기간·봉·모양을 구분합니다. 모양 버튼의 글자가 세로로 갈라지던 기존 CSS 충돌을 제거했습니다.
- 화면 크기를 바꿀 때 가격 차트를 복제하지 않습니다. 호가를 대화상자로 연 상태에서 PC 폭으로 확대하면 대화상자를 닫고 오른쪽 호가 한 개만 사용합니다.
- 목록의 숫자 영역도 종목 선택으로 이어집니다. 관심 버튼·비교 입력·선택한 텍스트는 행 열기를 실행하지 않습니다. ‘빠른 확인’ 버튼과 별도 미리보기 창은 제거했습니다.
- 비교 체크박스는 기존 비교 선택 모드에서만 표시합니다.
- 종목을 연 뒤 다른 종목으로 이동해도 원래 목록의 필터·정렬·복귀 위치를 유지합니다. 종목 진입 후 스크롤 이동은 화면 갱신 다음 프레임에 적용합니다.
- 회사 제목은 고정하지 않습니다. 자료 탭 조회 중에도 회사·가격·상위 탭을 유지하고 상태 메시지를 탭 아래에 둡니다.
- ‘실적의 흐름’은 시세 첫 화면에서 제거하고 기업 분석의 ‘실적과 주가’ 아래 및 재무 화면에 배치했습니다.
- 호가는 매도 10단계·매수 10단계를 같은 가격 열에서 읽도록 정리했습니다. 체결 자료·시장 구분·재연결 공백은 기존 계약을 유지합니다.
- 흰색/다크 배경과 주식담 녹색 토큰, 움직이지 않는 hover 규칙을 유지합니다. 새 의존성은 추가하지 않았습니다.

## 참고 화면과 적용 판단

작업 전 부모 작업에서 2026-10-11에 수동 확인한 화면을 기준으로 했습니다. 토스 `A005930/order`의 회사 요약·차트·호가 구분, Google Finance `005930:KRX`의 넓은 차트와 하단 재무 구조를 참고했습니다. 주문 열은 추가하지 않았습니다. 당시 계획 모드의 외부 사이트 캡처는 인라인 기록이며 저장소에 복사하지 않았습니다.
