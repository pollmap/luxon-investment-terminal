# v110 — 종목별 조회와 출처 중복 저장 개선

2026년 10월 10일 KST. API·수집기를 v109 읽기 버전, v110 활성화 버전 순으로 배포했습니다. 화면은 기존 v102 정적 산출물을 유지합니다. **전 종목 데이터와 성능 목표의 전체 완료 기록은 아닙니다.**

## 실제 공개 반영

- API·수집기: `20261010-storage-writes-v110`.
- 읽기 호환 롤백: `20261010-reader-floor-v109`.
- 정적 화면: `20261010-chart-projection-v102`. 기존 주소와 Cloudflare 주소, 관심종목·설정은 그대로입니다.
- DB·Redis·OpenAlgo·정적 웹을 교체하지 않았습니다. 쓰기 설정 활성화 때에는 수집기만 재시작했습니다.
- 공개 health·삼성전자 quote·financials·summary가 모두 HTTP 200이며 배포 파일과 실행 이미지의 소스 해시를 대조했습니다. 재무와 요약 응답은 v109/v110 간 같은 내용 해시를 유지했습니다.

패키지·실행 파일 SHA, 공개 요청 결과, 저장 설정, 수집 현황은 [검수한 공개 근거](evidence.json)에 있습니다. 인증정보·원문 응답·운영 로그는 포함하지 않습니다.

## 저장 공간과 남은 검증

기존 시계열 전체의 출처를 공유 저장하는 변환은 **로컬 복원본의 별도 스키마**에서 검증 중입니다. 운영 DB의 기존 시계열을 교체하거나 삭제하지 않았습니다.

첫 시험은 진행 파일을 교체할 때 Windows 파일 접근 오류로 중단됐습니다. 원본 DB·덤프와 이미 커밋된 후보 행을 보존했습니다. 이후 원본 대조 결과 후보 2,976,000행을 확인하고, 파일이 아닌 같은 DB 트랜잭션의 체크포인트로 재개하도록 고쳤습니다. 전체 대조와 물리 크기가 나오기 전에는 운영 DB 공간 회수를 완료로 표시하지 않습니다.

공개 100동시 검색 p95 300ms·상세 요약 500ms 목표는 아직 미달입니다. 이번 4개 순차 공개 요청은 상태 확인이며 부하 성능 측정이 아닙니다. 현재 UI를 바꾸지 않았으므로 신규 디자인 검증으로도 보고하지 않습니다.

## 저장소 검증

현재 앱의 자동 검사 workflow와 [실행 안내](../../CI.md)를 추가했습니다. 과거 터미널 workflow는 수동 실행으로 보존합니다. 실제 공급자·운영 DB·배포 키 없이 fixture로 검사하며, Linux CI에서는 패키지 설치 이후 외부 네트워크를 격리합니다.

- 로컬 Windows Python 1,326개 통과, 외부 연결 검사 4개 제외.
- Node 순수 함수 69개, 브라우저 핵심 동선 13개 통과.
- 타입 검사, 정적 candidate 빌드, 73개 산출물의 무결성·HTML·PWA 검사 통과.
- CI runner와 관련 변경 3개 파일의 Ruff 검사 통과. 저장소 전체의 lint 통과를 뜻하지 않습니다.
- 오래된 재무 fixture는 새 종목 식별 조회에 맞춰 실제 종목 목록을 저장하도록 고쳤습니다. 기존 응답 검증은 유지하고 전체 시장 조회가 다시 들어오면 실패하게 했습니다.

이 결과는 로컬 검사입니다. GitHub Actions의 Linux 결과와 실제 공개 데이터·성능·장중 수신은 별도 확인 대상입니다. 로컬 candidate를 새로운 공개 화면 버전으로 배포하지 않았습니다.
