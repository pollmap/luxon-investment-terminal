# v42 — 검증된 주식분할을 기업행사·성과 원장에 연결

공개 버전 `20261004-split-events-v42`. 프런트엔드·주소·관심종목 설정은 유지했다. DB와 다른 VPS 서비스를 교체하지 않았다.

## 실제 누락과 변경

삼성전자 `share-basis:005930`에는 검토한 50:1 분할과 공시 원문 근거가 있었지만 `events:005930`의 split 행은 0건이었다. 실적 비교선에 사용한 분할이 기업행사 원장과 성과 계산에는 전달되지 않는 상태였다.

`split_events.py`를 추가하고 기업행사 수집의 첫 단계에 연결했다. 기존 검토된 complete_split_history·원천 해시·회사의 DART 식별·종목코드가 일치할 때만 실제 분할의 날짜와 new_shares/old_shares 비율을 원장에 저장한다. 보통주 검토를 우선주로 복사하지 않는다. 아직 도래하지 않은 분할을 실현된 행사로 넣지 않는다.

동일 종목·날짜의 기존 행이 같은 검증 비율이면 재사용한다. 미검증 또는 상충하는 기존 행은 덮어쓰지 않고 split-event-review에 기록하며, 관련 전체 기업행사 coverage를 계산 불가로 바꾼다. 기존 재무 사실·가격·분할 검토 입력은 수정하지 않는다. 액면 변화가 없는 자사주 소각은 분할로 만들지 않는다.

이 연결은 배당·모든 기업행사의 전체 확보를 의미하지 않는다. coverage를 자동 verified로 올리지 않으며, 배당락일·권리·지급일·기타 행사가 부족하면 performance는 계속 계산을 막는다. 검증된 입력에 기반한 기존 성과 원장의 분할/병합 수량 처리를 사용한다.

## 검증

관련 테스트 37개 통과. 정확한 비율·반복 중복 방지·원본 보존·잘못된 종목/회사/해시/비율 거부·기존 상충 행 보존·불완전한 coverage 유지와 가격/경제적 가치가 유지되는 분할·병합 성과를 검사했다. 성과 테스트의 coverage는 fixture_non_production이며 운영 coverage로 사용하지 않았다.

운영 DB 최초 감사에서 삼성전자 분할 이벤트 0건을 확인했다. 공개 배포 후 수집기가 1건을 연결했고, 별도 재처리 점검에서는 added 0으로 재사용됐다. 원천 share-basis/prices/raw bars의 전후 해시가 같았다. 공개 events API에 종목코드 005930, 비율 50, 원천 basis_id와 DART URL이 전달되고 health 버전도 일치했다. 전체 기업행사 coverage는 여전히 verified false다.

저장된 reviewed share-basis의 효력일은 2018-05-03이다. 삼성전자 공식 IR은 새 주권의 변경상장일을 2018-05-04로 설명한다. 효력일과 거래 재개/변경상장일을 같은 필드로 바꾸지 않았다. 이번 연결은 이미 검토된 주식 단위 이력을 재사용한 것이며, 분할 일자를 가격 급락으로 추정하지 않았다.

근거: `work/remaining-v42/before.json`, `live.json`, `public.json`, `tests.xml`, `samsung-capital.html`. 회사 공식 상장 정보: https://www.samsung.com/global/ir/stock-information/listing-Info/ . DART 원문 URL은 public.json에 있다.

## 남은 완료 조건

다른 종목·전체 기간의 분할 검토, 배당락일·기업행사 및 전체 범위와 지급일 연결, 배당 재투자의 실제 자료 검증이 남아 있다. 전 종목 과거 자료·404·TTM 확대·추가 지표, 실제 장중 수신/복구, 공개 성능·실제 사용자 과제도 미완료다. 이번 버전을 전체 배당 성과 완료나 공개 성능 개선으로 보고하지 않는다.
