## v89 코드 수정과 검증

- EPS 공개 시점은 분자·분모·보고 EPS 입력이 모두 공개된 시점으로 계산합니다. 결과 추적에도 해당 시점과 입력 ID를 남깁니다.
- 정정 누적 자료가 오래된 단독 분기를 갱신할 수 있게 했습니다. 앞선 기간만 정정됐을 때는 새 앞선 값과 오래된 후속 누적값을 차감하지 않습니다.
- 연결/별도 문맥 충돌과 기간 종료 전 공개 시점은 제외합니다. 같은 EPS 값이 서로 다른 주식분할 기준에 연결되면 보고값은 보존하되 비교선을 막습니다.
- 배당의 미해결 날짜 충돌을 일부 자료 재처리로 지우지 않습니다. 실제 지급일이 없는 `confirmed`와 날짜 순서 충돌을 검증 완료로 처리하지 않습니다.
- `multiple_required`는 표시 구간에 양수·비교 가능한 입력이 실제 존재할 때만 반환합니다. 자료 없음과 음수 지표는 각각의 원인을 유지합니다.
- `worker_snapshot()`은 원본 worker 상태·시각을 보존하고 heartbeat가 오래되거나 잘못된 실행 상태만 `degraded`로 표시합니다. 기준은 기본 15분 또는 설정된 전체 목록 갱신 간격의 3배 중 큰 값입니다. 자료 확보율·저장 데이터는 바꾸지 않습니다.

최종적으로 계산·분할·배당·분석 상태·worker 상태·기존 범위를 합친 **15개 테스트 파일, 136개 검사**가 통과했습니다. 이 검사는 인위적 경계 사례에 대한 코드 검증이며 실제 미수집 자료를 확보한 결과가 아닙니다.

아직 공개 관측은 v88입니다. v89의 실제 배포·동일 응답 재검증·PC/모바일 화면 검증은 배포 기록에서 별도로 확인해야 합니다. 장중 수신, 전 종목 원문 검증, 배당 날짜 보완 및 100동시 성능은 이번 조사 범위에 포함하지 않았습니다.
