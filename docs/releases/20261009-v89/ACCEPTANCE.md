> 아래는 v89 개발 중 관측을 보존한 기록입니다. 이후 실제 배포·DB 복원·자료·화면 검증 결과는 [v92 검증표](../20261009-v92/ACCEPTANCE.md)를 우선합니다.

2026-10-09 KST. 작업 중 기록입니다. **전체 완료 판정은 아직 하지 않았습니다.** 사용자 선택은 세 번째 이미지인 ‘주식담’입니다. 최신 범위는 코스피·코스닥 보통주·우선주, 토스 단일 증권사, DART 기업 자료, 로그인 없는 PC·모바일 웹입니다. 코넥스·ETF·주문·계좌·배당 재투자는 제외합니다.

## 작업을 끝내는 기준

기능을 추가하는 대신 확정 계획의 검증표를 닫습니다. 한 항목의 코드·실제 자료·화면·공개 반영을 별도로 판정합니다. 통과한 검사는 변경이나 새 실패가 생기지 않으면 반복하지 않습니다. 외부 조건으로 확인할 수 없는 항목은 구체적인 근거와 다음 실행 조건을 남기며 성공으로 바꾸지 않습니다.

## 운영 복구 증거

- 확인 당시 디스크 사용률은 97%였고 수집 컨테이너는 실제로 종료된 상태였습니다. `docker ps`의 표시만으로 정상 작동을 판정하지 않았습니다.
- 비활성 배포본 91개를 로컬 압축본으로 보관했습니다. 160,224개 파일·논리 크기 14,521,259,254바이트를 검증했고 현재·최근 롤백본·실행 중 이미지가 참조하는 배포본은 보존했습니다.
- 보관 파일 SHA-256: `708b91746c9934a3c46e62709e5e6db1347b0c865e8e43227ab39191cf7855a0`.
- 실제 배포본 한 개를 별도 임시 경로에 복원하여 1,773개 파일·161,012,815바이트를 해시 대조했습니다. 이는 앱 배포본 복원이며 DB 복원을 뜻하지 않습니다.
- 기존 원본 봉투 159,513개 감사에서 JSON 손상 115개를 발견했습니다. 113개는 0바이트이고 2개는 잘린 자료입니다. 해당 원본을 삭제하거나 복구했다고 처리하지 않았습니다. 새 수집에서 같은 실제 응답이 확보되면 손상 메타데이터를 보존하면서 복구하는 경로를 추가했습니다.
- 새 DB 백업 `market-20261008T153201Z.dump`: 2,047,457,606바이트, SHA-256 `0022244d1f67ceb0147535da413eaf64fac49c42cc51652c5ce64e7d7bba92b8`. 덤프 목록 검사는 통과했습니다. 로컬 격리 DB 복원 검사는 준비 중입니다.

## 현재 검사 결과

- 통합 백엔드 회귀: 20개 관련 파일의 200개 검사 통과. 인위적 경계 사례에 대한 검사이며 실제 원천 수집과 다릅니다.
- 시장 공시: 13개 검사 통과.
- 프런트엔드: 생산 빌드 통과. 추가 장중 선 간격 개선 후 최종 빌드를 다시 검증합니다.
- UI 회귀는 필터·기간·뒤로 가기·부분 실패·재시도·다른 종목 응답 차단·중복 관심 터치·큰 글씨 유지 등을 검사했습니다.
- 시안의 예시 기사·수치를 운영 화면으로 복사하지 않았습니다. 개발 화면의 뉴스 실패는 새 API가 아직 공개 서버에 배포되지 않은 상태를 그대로 나타냅니다.

## 완료에 필요한 남은 증거

1. 같은 v89 API·웹 버전 공개 배포, 수집 프로세스와 새 heartbeat, 토스 산업·DART 공시·뉴스 투영 실제 응답.
2. 운영 삼성전자우 배당 투영과 새 배당락 근거 연결, 전 종목·자료·기간별 미수집/오류 집계.
3. 장중 실제 체결·호가와 재연결 후 화면 반영. 휴장 중 승인으로 대체하지 않습니다.
4. 공개 인터넷 100동시 요청의 검색·상세 지연과 브라우저 성능 재측정. Cloudflare 검증 주소는 현재 Python 403/1010, 인앱 브라우저 `ERR_BLOCKED_BY_CLIENT`로 접근되지 않아 우회하지 않았습니다.
5. DB 격리 복원, 앱 롤백, 디스크 재개 조건과 실제 수집 재개.
6. 실제 Android·iOS와 아버님·처음 사용하는 이용자의 과제 수행. 데스크톱 크기 변경 검사는 실제 기기/실사용 평가를 대신하지 않습니다.
