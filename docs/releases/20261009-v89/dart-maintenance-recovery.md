## 수정

- `_dart_get`에서 status 800을 별도로 분류하고 모든 DART 요청이 공유하는 **15분 재시도 대기**를 저장합니다. 새 수집기 객체나 다른 종목이 같은 점검 응답을 계속 요청하지 않습니다.
- 회사 목록 갱신은 단일 실행 잠금을 사용합니다. 정상 ZIP·회사 식별 형식·빈 목록·중복 충돌을 확인한 경우에만 기존 목록을 교체합니다.
- 갱신 실패 시 기존 회사 식별 목록과 기준일을 그대로 반환하고, 갱신 작업 상태에 실패 종류·원문 해시·다음 시도를 별도로 기록합니다. 오래된 목록을 새 자료처럼 날짜만 바꾸지 않습니다.
- 기존 목록이 없으면 빈 목록을 정상 응답으로 반환하지 않고 실패 상태를 유지합니다.
- 일반 ZIP 형식 오류는 목록 갱신만 대기시킵니다. 전역 점검 중단은 실제 status 800이 확인된 경우에만 적용합니다.
- 신규 정상 목록은 KST 날짜와 원문 해시를 보존합니다. 공급자 점검 메시지·키·요청 매개변수는 예외 메시지에 포함하지 않습니다.
