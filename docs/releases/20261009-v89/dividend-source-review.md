# 배당 원문 연결 보완

2026-10-09 KST. 인증이 필요 없는 공식 IR·KIND 원문을 조회해 파서와 연결 경로를 검증했습니다. 최초 검토는 로컬에서 수행했고, 이후 v89 운영 투영과 공개 API 확인까지 진행했습니다. 배당 재투자는 제외 범위입니다.

## 찾은 누락과 수정

**삼성전자우가 원문에 있어도 수집되지 않는 경로를 수정했습니다.** DART 회사 목록은 보통주 코드에 법인을 연결합니다. 기존 기업행사 수집기는 삼성전자우의 법인코드가 없으면 종료했고, 보통주 원문에서도 보통주 행만 읽었습니다.

`preferred_dividends.py`는 검토된 회사·종목 연결을 확인한 뒤, 삼성전자 공시의 **‘삼성전자우 / 우선주 / 1주당 배당금(원)’** 부속표와 본문의 종류주식 금액을 대조합니다. 금액이 다르거나 이름·주식 종류가 불명확하면 연결하지 않습니다. 이미 보관한 DART 원문의 해시를 검증해 읽으며 추가 DART 요청을 만들지 않습니다. 정정 전후 이벤트와 원문은 보존합니다.

실제 삼성 공식 IR 공시에서 **2025-09-30 기준 370원, 지급 예정 2025-11-19**를 읽었습니다. 보통주가 우연히 같은 금액이어도 이를 복사하지 않았습니다. 원문은 예정일을 제시하므로 실제 지급 확인으로 바꾸지 않습니다. [삼성전자 공식 공시](https://www.samsung.com/sec/ir/reports-disclosures/public-disclosure/3645/)

**배당락일이 실제 지급 확인에 종속되던 수집 조건도 수정했습니다.** 기존 KIND 연결은 현대차 IR의 실제 지급일이 있어야 배당락일을 붙였습니다. 이제 검토한 특정 DART 접수번호·종목·주식 종류·기준일이 일치하는 경우에도 배당락일만 독립적으로 보완합니다.

| 확인한 원문 | 연결한 값 | 실제 지급 확인 |
|---|---|---|
| SK하이닉스 KIND 배당락 공시 | 보통주, 배당락 2025-05-29. DART `20250423800599`의 기준일 2025-05-31·375원과 연결 | 이번 자료로 확인하지 못함 |
| 현대차 KIND 배당락 공시＋회사 IR 지급 이력 | **현대차2우B**, 기준일 2026-05-31·2,500원·배당락 2026-05-28·지급 2026-06-30 | 원문 간 대조 통과 |

현대차 검색 결과에는 회사명만 먼저 보였지만 실제 배당락 공시는 **2우선주B**를 지칭했습니다. 보통주나 다른 우선주로 확대 적용하지 않았습니다. [SK하이닉스 KIND 원문](https://kind.krx.co.kr/external/2025/05/28/000380/20250528001029/99335.htm), [현대차2우B KIND 원문](https://kind.krx.co.kr/external/2026/05/27/000563/20260527001268/99335.htm), [현대차 IR 지급 이력](https://www.hyundai.com/worldwide/en/company/ir/stock-information/shareholder-return-policy)

현대차 IR 표는 보통주와 각 우선주에 22개 지급 이력 행을 제공합니다. 21개는 기존 검토 조건을 통과했고, **2018-06-30 기준 배당의 지급일이 2019-08-14로 적힌 1행**은 긴 지급 지연 검토 대상으로 남겼습니다. 날짜를 임의로 고치지 않았습니다.

## 원본·검증·반영 경로

- 실제 원문과 SHA-256: `work/issuer-dividend-review/manifest.json`, 같은 폴더 HTML 원본.
- 실제 원문 파싱 및 현대차2우B 날짜 대조 결과: issuer-dividend-evidence.json (로컬 보존 자료: `issuer-dividend-evidence.json`).
- 운영 연결: 기존 `collect_events` → 우선주 아카이브 투영 또는 기존 IR/KIND 수집 → `dividend-observations` → `enrich_dividends` → 기존 기업행사 API.
- 삼성전자우의 운영 투영은 `project_preferred_dividends(store, '005935')`로 실행합니다. 원본이 없으면 `issuer_document_not_collected` 또는 `issuer_archive_missing`이며 원천 미제공으로 분류하지 않습니다.
- KIND 수집은 기존 자동 기업행사 작업 경로를 그대로 사용합니다. 저장 원본·종목별 체크포인트·이전 정상 결과를 보존합니다.

배당·우선주·읽기 전용 복구 관련 **48개 검사**와 변경 모듈의 문법 검사가 통과했습니다. 우선주 금액/총액 혼동, 잘못된 종목명, 본문·부속표 불일치, 정정 자료의 역전, 아카이브 누락, 배당락과 지급 상태의 독립성을 검사합니다. 실제 원문 파싱 검증과 모의 회귀검사는 구분합니다.
