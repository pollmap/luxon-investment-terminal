## 1초 캐시 경계 수정

Nginx는 만료 초가 현재 초보다 작을 때 만료시킵니다. 종전 절대 만료값의 `+1` 때문에 검증 후 1.3초가 지난 요청에도 같은 검증시각의 HIT가 반환됐습니다.

`services/market_dashboard/app.py`에서 절대 만료값을 원래 검증시각의 초 단위 내림으로 수정했습니다. 잘못된 값·미래 값은 원값을 보존하고 두 공유 캐시에서 제외합니다. 원천 거래시각이나 검증시각을 새 값으로 바꾸지 않습니다.

- Python 회귀 63개, Cloudflare Worker 검사 22개 통과.
- 실제 공개 Nginx 경로에서 검색·상세 요약을 각각 조회하고 1.3초 후 다시 조회했습니다. 두 번째는 모두 EXPIRED이고 새로운 검증시각으로 응답했습니다.
- 이 변경은 정확성 수정입니다. 캐시 적중 시간이 줄어들 수 있으며 속도 향상으로 포장하지 않습니다.
- 기록: `work/operations-20261009-v94/v101-live-operations.json`.
