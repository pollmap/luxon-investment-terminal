# v28 — 삼성전자 과거 EPS·주식분할 연결

## 구현과 실제 자료

- DART 2016·2017·2018 사업보고서 연결 EPS 주석의 당기·전기 숫자를 확인했다. 보통주 귀속이익(백만원), 가중평균 주식 수(천주), EPS(원)를 구분해 18개 사실을 추가했다.
- 원문 HTML·해시·공시 식별자·실제 공개일과 매핑 근거를 보존했다. 기존 XBRL의 잘못된 EPS 단위를 덮어쓰지 않았다.
- 삼성전자 보통주의 2018-05-03 효력 발생 50:1 분할을 반영했다. 재작성된 비교기간에는 분할을 중복 적용하지 않는다. 검토 범위는 2016-01-01~2026-06-30이며 그 밖의 기간까지 확인한 것은 아니다.
- 기존 최근 TTM EPS 10개 결과가 재투영 후 유지됐다. 이번에 추가한 과거 주석은 연간 자료이며, 과거 TTM 전체 확보를 의미하지 않는다.
- 화면·표·CSV·차트 설명에 ‘분할 기준 주가’를 사용한다. 공개 화면 검수에서 발견한 동일 연도 요약값·공시값 중복은 검증된 공시를 우선해 제거했다. 실제 기간 시작일이 다른 자료와 원본 정정 이력은 보존한다.

## 검증

- EPS·주당지표·분할·원문 매핑 등 관련 테스트 56개 통과.
- 실적 표 중복 수정 후 관련 회귀 테스트 23개 통과. 위 56개와 중복되므로 합산하지 않는다.
- 웹 lint 오류 0개, 기존 경고 10개. Next.js 빌드와 TypeScript 검사 통과.
- v28b 공개 화면에서 분할 기준 표시·기간·숫자 확인. 배포 직후 목록 일시 오류는 재조회 후 해소됐다.
- v28c(`20261004-split-units-v28c`) 공개 health와 화면을 확인했다. EPS 연간 실적은 중복 없이 9개 기간, 공개 화면의 2025년 EPS는 6,605원·전년 대비 +33.4%다. 차트의 분할 기준 표시와 실제 그래프를 스크린샷으로 확인했다.
- 공개 API 재검사에서 연간 EPS·연간 FCFE·TTM EPS 모두 ready. FCFE 2024·2025 두 기간이 유지됐다. TTM 응답은 정정 중복을 제거한 6개 기간이며 이는 원본 계산 결과 10건과 다른 집계다. `work/remaining-v28/public-final-audit.json`에 결과를 기록했다.
