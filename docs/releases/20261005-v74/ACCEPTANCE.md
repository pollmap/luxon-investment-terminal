# v74 — Toss 404 원천 분류와 백엔드 범위 정합성

## 변경

- 최신 Toss KOSPI·KOSDAQ·기타 종목 목록이 모두 정상 수신되고 목록 갱신 후 2일 이내일 때만 404를 분류한다.
- 국내증시의 유효 종목이 Toss 목록에 없으면 `provider_catalogue_omission`으로 기록한다. 종목은 검색 범위에 남기고 마지막 정상 자료와 404 이력을 보존한다.
- 해당 코드별 Toss 목록 해시가 바뀌지 않으면 7개 종목 자료를 재호출하지 않는다. 목록에 종목이 새로 나타나면 다시 요청한다.
- 진단에 원본 응답의 전체 추적 객체를 복사하지 않고 목록 시각·행 수·심볼 해시만 저장한다.
- 시작 시 기존 404 작업을 재분류하고 내부 자료 커버리지 감사에 해당 상태를 별도 집계한다.
- `/health`의 종목 수를 저장된 과거 작업 카운터가 아니라 현재 KOSPI·KOSDAQ 유효 종목 범위로 반환한다. 백필 작업은 2개 상장형 수익증권과 코넥스를 계속 제외한다.
- 백엔드 API·수집 작업자만 배포한다. 웹·OpenAlgo·PostgreSQL·Redis와 다른 호스트 서비스는 재시작하지 않는다.

## 로컬 검증

- `source_support`, `toss_backfill`, `toss`, `toss_market`, `market_data_integrity`, `public_market`, `service_scope`, `market_release` 관련 pytest 모듈 통과.
- Ruff `F` 검사와 수정 모듈 Python 컴파일 통과.
- 검증 항목: 목록 부재와 엔드포인트 오류 구분, 작은 진단 크기, 동일 목록 해시에서 재요청 없음, 목록 변경 시 재시도, 기존 이력 보존, 현재 종목 분모 표시.

## 공개 검증

- 활성 버전: `20261005-provider-catalogue-404-v74`.
- `GET /api/market/v1/health`: HTTP 200, 공개 release v74, 유효 종목 2,766.
- 094800 검색·요약·가격 창: 모두 HTTP 200. 검색 1건, 종목명 맵스리얼티.
- 094800 가격 창은 2014-07-11~2026-10-02의 공개 일봉 자료 중 선택한 242개 거래일을 반환하고 출처는 `naver`로 남는다. 토스 시세로 잘못 표시하지 않는다.
- 수집 작업자 DB 검사에서 094800의 Toss `history`, `raw-history`, 투자자, 프로그램, 공매도, 신용, 대차 7개 작업이 모두 `not_in_provider_catalogue`로 분류되고 목록 revision을 보유한다. 해당 코드의 유효 종목 등록은 유지된다.
- 검색·상세·웹 화면은 응답했다. DB·Redis·웹·OpenAlgo 컨테이너 ID를 교체하지 않았으며 다른 서비스는 확인된 실행 상태를 유지했다.

## 범위와 남은 항목

이 배포는 Toss가 094800에 해당 자료를 제공하도록 만들지 않았고, 다른 제공 원천의 동등한 수급·공매도·대차·신용 값을 확보한 것도 아니다. 전 종목 과거 수집·TTM/분할 검증·배당 이력·실제 장중 이벤트 수신·100동시 공개 성능·아버님 실사용 평가는 계속 남아 있다. 수집 시도 횟수만으로 처리량 개선을 주장하지 않는다.
