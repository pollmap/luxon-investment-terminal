# v50 — 주식 기준 변경과 TTM 분석 캐시 연결

공개 버전: `20261004-analysis-basis-v50`. 기존 주소·프런트·사용자 저장값·재무 원본·다른 VPS 서비스는 유지했다.

## 수정한 문제

분석 조회가 `official:{code}`의 변경만 확인하고 독립된 `share-basis:{code}`의 변경을 확인하지 않았다. 검증 근거가 갱신되거나 철회된 경우 이전 분석 캐시가 남을 수 있었다. 이번 조사에서 세 기업의 기존 근거 ID는 서로 일치했다. 현재 값이 틀렸던 사건으로 보고하지 않는다.

분석 캐시는 이제 재무 원본과 주식 기준의 두 버전을 확인한다. 독립된 주식 기준이 있으면 이를 사용하며, 빈 객체로 철회된 근거도 이전 내장 근거로 대체하지 않는다. 입력에 남아 있는 이전 `per_share_basis` 확인 표시는 제거한 뒤 현재 검증 근거로 재검사한다. 원본 값·문서·사실 ID는 수정하지 않는다.

계산 도중 의존 자료가 변경되면 그 결과를 캐시에 게시하지 않는다. 회사 소개 등 다른 조회는 재무 원본 버전만 확인하는 기존 구조를 유지한다. 과거의 주식분할 정규화 값은 재차 분할 적용하지 않으며, 현재 기준과 맞지 않으면 계산을 제한한다.

## 검증 결과

- 관련 캐시·EPS·주식분할·주식 기준·분석 시계열 테스트 36개 통과.
- 실제 계산 테스트에서 근거 없음 → 확인된 근거 적용 → 근거 철회의 순서로 TTM 미계산 → 계산 → 미계산 전환을 확인했다. 테스트 자료이며 기업의 새로운 실적 근거가 아니다.
- 공개 서버 세 기업에서 원본 버전 보존, 독립 주식 기준 버전과 분석 캐시 버전 일치 확인.
- 현재 저장된 입력으로 계산 가능한 TTM 행은 삼성전자 10, SK하이닉스 28, 현대차 32로 수정 전과 동일하다. 연결/별도·여러 회계기간의 행 수이며 회사 수나 확보된 연수로 해석하지 않는다.
- 공개 health와 삼성전자 지표·EPS 분석, SK하이닉스 EPS 분석 HTTP 200. health의 배포 버전이 v50과 일치하고 작업자가 수집 중임을 확인했다.
- 단일 HTTP/1.1 공개 조회의 관측 시간은 지표 약 1.73초, 삼성전자 분석 약 0.50초, SK하이닉스 분석 약 0.51초였다. 100동시 요청·p95 시험이 아니므로 목표 달성의 근거로 사용하지 않는다.

근거 파일: `work/remaining-v50/tests.xml`, `basis-before.json`, `inputs-before.json`, `actual.json`, `public.json`. 변경 코드: `services/market_dashboard/official_views.py`, `tests/test_official_views.py`.

## 전체 완료와 구분

이 변경은 확보된 주식 기준을 자동 재계산에 연결한 것이다. 다른 기업의 검증 근거나 기간을 늘리지 않았다. 세 기업에서도 자료 단위·공개 시점·귀속이익/주식 수·상충 입력·EPS 대조·주식 기준 때문에 계산하지 못하는 행이 남아 있다. 기존 검증 종료일 밖 자료에 확인 표시를 복사하지 않았다.

전 종목 과거 수집과 404 보완, 기업별 TTM·분할 기준 확대, 배당락일·실제 지급일·기업행사와 재투자, 실제 장중 체결·호가 수신/복구, 공개 100동시 검색 300ms·상세 요약 500ms 및 실제 사용 과제는 미완료다. 휴장 중 구독 승인과 API 200을 장중 검증이나 서비스 전체 완료로 처리하지 않는다.
