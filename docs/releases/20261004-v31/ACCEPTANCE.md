# v31 토스 404 종목의 보완 일봉 확대

배포: `20261004-fallback-history-v31`.

## 실제 결과
- 404가 남은 110종목은 코넥스 107종목·코스피 3종목이었다. 모두 기존 네이버 일봉이 있었으며 토스 지원 여부와 별도로 관리했다.
- 이 110종목을 기존 수집기·속도 제한으로 갱신했다. 실패 0건, 34종목에서 총 7,451개 일봉이 추가됐다.
- `094800`, `136660`은 2,600행에서 3,000행으로 늘었다. 최초 저장일은 2016-02-26에서 2014-07-11로 확장됐다. 두 종목 모두 공개 KRX 일봉 조회에서 3,000행·네이버 출처를 확인했다.
- 운영 근거: `work/remaining-v31/fallback-refresh.jsonl`. 토스 404 진단은 삭제하지 않았다.

## 변경과 검증
- 2,600행으로 고정된 요청을 20,000행 요청으로 늘렸다. 실제 원천 응답이 3,000행에서 제한될 수 있어 `history_complete=false`와 `provider_window_only`를 유지한다.
- 원래 저장된 더 오래된 행을 삭제하지 않고 정규화 시계열로 보존한다. 빈 응답·다른 공급자 자료로 정상 이력을 덮어쓰지 않는다.
- 기존 캐시도 새 범위로 한 번 갱신한다. 이후에는 기존 TTL을 유지한다.
- 관련 테스트 33개 통과. 배포 후 웹·API health 검증을 수행했다. 일괄 보완 중 웹은 유지하고 수집 작업자만 일시 중지했으며 종료 시 다시 시작하도록 했다.

## 남은 범위
보완 일봉은 분할 조정 방식이 미확인이다. 토스 통합 시세·분봉·수급·호가와 동일한 자료로 간주하지 않는다. 404 자체, 제공 창 이전의 역사, 배당·TTM·장중 검증·성능 목표는 별도로 남아 있다. 공개 화면에서의 핵심 동선 및 실제 사용자 평가도 전체 완료 조건이다.
