# v62 — 불필요한 분석 제외와 우선주 재무 화면 복구

사용자 최신 요청에 따라 배당 재투자·총수익률 비교는 출시 범위와 완료 조건에서 제외한다. v60에서 공개 화면 진입과 동적 로딩을 제거했으며, 이번 버전도 유지한다. 배당금·배당수익률·지급 이력과 주식분할 검증은 유지한다. 기존 원본과 호환 API를 삭제하지 않는다.

## 구현과 실제 자료

검증된 회사 식별 연결에 한정해 삼성전자우(005935), 현대차우(005385), 현대차2우B(005387), 현대차3우B(005389)의 회사 재무총액·보고기간·실적 추세·회사 TTM 금액을 발행회사 자료에서 조회한다. 독립 가격·EPS/BPS·배당·주식 수는 복사하지 않는다. 직접 DART 회사 연결이 생기거나 종목명이 변경되면 검토 연결을 적용하지 않는다. 원본 재무 스냅샷과 정정 이력은 보존하며 주당 계정은 공유 응답에서 제외한다.

우선주 자체의 official 자료가 없으면 재무제표 컴포넌트를 열지 않던 조건을 제거했다. 빈 보조 지표 표를 반복 표시하지 않는다. 회사 재무총액 TTM은 우선주 TTM EPS 검증을 의미하지 않는다.

## 검증

- 관련 Python 테스트 44개 통과: 회사 연결·계정 분리·정정 캐시·연결 철회·수집 요청·TTM·기존 EPS/가치평가 회귀. 기록 `work/remaining-v61/tests.xml`.
- 변경 프런트엔드 타입검사·ESLint·Next.js 프로덕션 빌드 통과.
- 공개 4종목 재무 API와 연간 추세 200. 2025 연간 연결 응답 삼성전자우 227계정, 현대차 우선주 각각 304계정. 주당 계정 제외 각각 2개/8개. 보고기간 색인 92개는 연결·별도 및 자료 없음 항목을 포함하며 92개 독립 실적기간 완료를 뜻하지 않는다. 기록 `work/remaining-v62/after.json`.
- 실제 인앱 브라우저에서 삼성전자우 기업 분석→재무 화면을 확인했다. 2015~2026 기간 선택, 2026 반기 재무상태표 표시, 2015 연간 선택 후 실제 과거 표 표시를 확인했다. 우선주 가격 201,500원은 별도로 유지된다. 전체 종목과 전체 계정 검수 또는 아버님 실사용을 대신하지 않는다.
- 공개 실행 버전 `20261004-preferred-financial-ui-v62`, 프런트엔드 BUILD_ID `nW8ejb3VHXWos1cxqiBbZ`. 기존 서버 경로·공개 주소 유지, 기대 버전 v61에서 한 번 승격했다.

## 남은 완료 조건

전 종목 과거 수집·404, 다른 우선주/회사 식별 검증, 지표별 주당 환산·TTM EPS·분할, 필요한 토스 조회 옵션의 실제 자료/화면 검증, 실제 장중 수신과 복구, 공개 성능 목표, 실사용 검증은 남는다. 배당 재투자 비교는 남은 작업이 아니다. 이번 변경만으로 전체 서비스 완료 또는 전 종목 완료를 보고하지 않는다.
