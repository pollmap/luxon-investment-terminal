# v65 — 과거 수집 상태와 공개 순위 보완

## 변경

다른 조회 경로에서 마지막 페이지까지 수집된 자료를 대기열이 계속 collecting으로 표시하는 문제를 수정했다. 최신 페이지 시각과 원천 마지막 페이지 확인, 남은 커서를 함께 검사한다. 조건이 충족되면 추가 API 요청 없이 실제 저장 행 수로 상태를 갱신하고 이전 상태를 backfill-status-review에 보존한다. 남은 커서가 있으면 완료 플래그만으로 수집을 건너뛰지 않는다. 방문 수를 유지하고 가격·자료 원본을 삭제하지 않는다.

토스 랭킹 수집과 기존 공개 랭킹 캐시에도 현재 종목 범위를 적용했다. 예전 코넥스 행이나 미등록 종목이 기존 스냅샷에 남아 있어도 공개 응답에서 제외한다. 원천 순위 번호와 원본은 보존한다. 메인 검색만 필터링하는 것으로 범위 적용이 완료됐다고 간주하지 않는다.
