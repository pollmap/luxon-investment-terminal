# 독립 복원본의 변경 자료 적용 — 로컬 구현

2026년 10월 10일. 공개 서비스 v124의 추가 데이터 확보 결과와 구분하는 운영 도구 기록입니다.

## 구현 범위

`delta_archive.py`는 날짜가 지난 복원본과 현재 자료의 차이를 전체 행·원출처 해시로 검증합니다. `pg_delta_sink.py`는 그 변경 파일을 **별도로 만든 로컬 PostgreSQL 후보 DB**에 적용합니다. 기존 복원본·체크포인트·운영 DB를 적용 대상으로 받지 않습니다.

- 실행 대상은 `127.0.0.1:54435`, 생성 작업에 연결된 DB 이름·소유자·OID·클러스터 식별자·디렉터리가 모두 일치해야 합니다.
- 검증한 두 테이블만 허용합니다. 다른 테이블·트리거·사용자 제약·체크포인트가 있으면 거절합니다.
- 전체 기준 자료를 먼저 대조하고, 변경 전 행의 원출처까지 확인해 추가·수정·삭제합니다. 원출처의 삭제·변경은 거절합니다.
- 직렬화 트랜잭션·단일 실행 잠금·디스크와 시간 한도를 적용합니다. 실패하면 롤백합니다. COMMIT의 성공 여부를 확인하지 못한 경우 자동 재시도하지 않습니다.
- 시작 응답이 유실된 경우도 롤백 또는 연결 종료 경로에 들어가도록 수정했습니다.

## 검증과 한계

변경 파일과 PostgreSQL 적용기의 순수 회귀 68개가 통과했습니다. 별도 PostgreSQL의 작은 시험자료에서 변경 전 값 대조, 중복 실행 거절, 예산 초과 롤백, 최종 전체 행·원출처 해시를 검증했습니다. 결과 파일에는 시험자료 여부·소스 해시·클러스터 종료 여부를 기록합니다.

이 코드는 로컬 후보의 적용기입니다. 현재 운영 스냅샷의 일관성 확보, 완결 복원본에서 후보 복제, 운영 수집 중단·재개, 최종 전환은 연결되지 않았습니다. 수천만 행에 대한 적용 속도도 아직 검증하지 않았습니다. **작은 시험 통과를 운영 원본 삭제나 디스크 회수의 근거로 사용하지 않습니다.**

진행 중인 대용량 복원은 정해진 시간·디스크 한도로 한 번 실행하며, 완료 또는 중단 결과를 별도로 남깁니다. 중단된 부분 결과를 완전한 복원으로 처리하거나 무한 재시도하지 않습니다.
