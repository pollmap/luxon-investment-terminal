# 실제 저장 상태 — 2026년 10월 10일 16:35 KST

공개 릴리스 v124의 운영 DB를 읽기 전용·일관된 한 트랜잭션으로 집계했습니다. 대상은 현재 범위의 코스피·코스닥 보통주·우선주 **2,765종목**입니다. 공급자를 다시 호출하거나 수집 작업을 변경하지 않았습니다.

## 과거 자료

다음 수치는 `backfill_complete=true`이며 다음 페이지 커서가 없는 작업 기록의 종목 수입니다. 최신 자료 갱신·원본 전체 재검증·화면 검증까지 모두 끝났다는 뜻은 아닙니다. `no_data`로 마지막 페이지를 확인한 종목도 포함할 수 있습니다.

| 자료 | 마지막 페이지 도달 기록 | 다음 페이지가 남은 종목 |
| --- | ---: | ---: |
| 일봉 | 514 | 2,162 |
| 투자자 수급 | 344 | 2,420 |
| 프로그램 | 710 | 2,054 |
| 공매도 거래 | 999 | 1,765 |
| 신용 | 1,042 | 1,722 |
| 대차 | 758 | 2,006 |
| 원주가 일봉 | 514 | 2,162 |

현재 이력 작업 기록의 HTTP 404·401·403 상태는 0건입니다. 별도로 공급자 목록에서 확인되지 않은 1종목이 각 자료에 남아 있습니다. 이 결과는 모든 과거 404 문제를 해결했다는 증거가 아닙니다. 전체 이력에 대한 원본 재검사나 모든 화면의 자료 일치를 이번 집계에서 수행하지 않았습니다.

자료별 집계는 서로 같은 종목 집합이 아니므로 더하거나 단일 완료율로 환산하지 않습니다. 모든 요구 자료를 완료한 종목 수는 이번에 산정하지 않았습니다.

원시 집계의 `end_of_history_and_current_ready`는 별도 `source_status`까지 요구합니다. 일봉 작업에는 이 메타데이터가 없는 경우가 있어 0으로 나왔습니다. 이를 일봉 자료가 없거나 마지막 페이지 확인이 0건이라는 뜻으로 해석하지 않습니다.

## 기업 분석·배당의 해석 경계

작은 분석 캐시만 검사한 결과, 현재 원본·주식 기준·계산 버전과 일치한 캐시는 382종목입니다. 2,270종목은 버전이 달라 재검증하지 않았고, 3종목은 조회 크기 제한, 110종목은 캐시 미생성으로 남았습니다.

그 382개 캐시에 숫자가 있는 연간 지표는 EPS 11종목·OCF 8종목·EBITDA 7종목, TTM EPS는 1종목입니다. **이는 모든 재무 원본을 다시 계산한 확보율이나 실제 차트 비교선의 종목 수가 아닙니다.** 음수 값도 숫자에 포함하며 가격 날짜·분할 기준의 최종 교집합을 검사하지 않았습니다. 기존 대표 종목의 공개 비교선 검증은 ACCEPTANCE 기록과 별도로 봐야 합니다. 배당 날짜·전 종목 분할 근거는 이번 집계 대상이 아닙니다.

기존 `collection`의 ‘ready’는 여러 세대의 상태 기록이 섞여 있습니다. 예를 들어 일봉은 2,765종목에 ‘자료 있음’ 기록이 있어도 전체 기간 완료는 위 표의 514종목과 다릅니다. 검증된 행 수·기간을 가진 영수증과 예전 존재 표시를 분리해 원시 집계에 남겼습니다.

## 실제 수집 제한

- 운영 디스크: 약 **89.85% 사용, 15.72GB 여유**. 가격·재무·XBRL·주식 기준·과거 거래 자료 수집의 `capacity_limited`가 계속 켜져 있습니다.
- DART 재시도 상태에는 공급자 점검 코드 `800`과 다음 재시도 시각이 기록돼 있습니다. 키나 인증 오류로 단정하지 않습니다.
- 최신 거래 자료의 정상 수신은 별도 v121·v122 증거가 있습니다. 이력이 멈춘 상태를 ‘전 종목 자동 수집 정상 진행’이라고 표현하지 않습니다.
- 대용량 외부 복원과 이후 변경 자료 검증이 완료되기 전에는 정상 원본 테이블을 지워 공간을 확보하지 않습니다.
