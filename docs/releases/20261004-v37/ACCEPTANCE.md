# v37 수급·공매도·대차·신용 과거 페이지 수집

공개 버전: `20261004-trading-burst-v37`. 이전 버전: `20261004-history-burst-v36`.
기존 공개 주소, 화면 빌드, 사용자 설정 및 DB를 보존했다.

## 변경과 판단

투자자·프로그램·공매도 거래·신용·대차 5종의 과거 조회도 한 차례에 최대 8페이지씩 진행한다. 기존 그룹별 호출 제한·공유 인증·Retry-After와 단일 작업자 구조는 유지한다. `MARKET_TOSS_TRADING_BURST`는 1~16페이지로 제한한다.

각 정상 페이지는 원본 근거와 함께 정규화 시계열에 저장하고, 다음 과거 커서를 함께 커밋한다. 뒤 페이지의 실패나 잘못된 종목·정체 커서는 앞 페이지를 지우지 않는다. 다음 실행은 저장한 커서부터 이어받는다. 기존 자료의 최신 페이지 확인은 한 페이지만 수행해 깊은 과거 커서를 보존한다.

화면용 수급·공매도·신용·대차 표는 각 페이지마다 다시 만들지 않고 묶음당 한 번 생성한다. 묶음 도중 실패해도 이미 저장한 정상 페이지를 표에 반영한다. 프로그램 요약은 전체 자료를 읽지 않고 최신 한 행만 사용한다. 나머지 표의 전체 재생성은 아직 유지하며 후속 최적화 대상이다.

전체 종목 순환과 사용자 관심 요청 배분은 기존대로 유지한다. 별도 인증 소유자나 중복 작업자는 추가하지 않았다.

핵심 파일: `services/market_dashboard/toss.py`, `services/market_dashboard/toss_backfill.py`, `tests/test_toss_backfill.py`.

## 로컬 검증

관련 테스트 61개 통과. 5종 자료의 8페이지 수집, 페이지별 근거, 묶음당 한 번의 표 생성, 뒤 페이지 오류에서 정상 자료·커서·표 보존, 재개 위치, 최신 조회의 깊은 커서 보존을 확인했다. 기존 범위 조회·누락값·시장 구분·공매도·신용 검사도 통과했다.

근거: `work/remaining-v37/tests.xml`. Fixture는 실제 수집 자료가 아니다.

## 공개 검증

배포 도구의 새 버전 health·웹·삼성전자 요약 검사 통과. 재시작 후 과거 수집의 전체 cursor와 phase를 유지했다. 기존 작업자에 현대차·NAVER의 5종 관심 요청을 등록했다. 실제 관찰: 2026-10-04 14:27:22~14:31:51 KST.

| NAVER 자료 | 이전 행 수 | 이후 행 수 | 이전 최초 날짜 | 이후 최초 날짜 |
|---|---:|---:|---|---|
| 대차 | 200 | 1,000 | 2025-12-09 | 2022-09-02 |
| 공매도 거래 | 300 | 1,100 | 2025-07-11 | 2022-04-05 |

공개 `financing?period=all`의 lending 1,000행·시작일 2022-09-02와 `short-selling?period=all`의 trades 1,100행·시작일 2022-04-05도 대조했다. 저장 증가가 공개 표 조회에 반영됐다(`work/remaining-v37/public-projection.json`).

각 자료에 800일의 실제 관측치가 추가됐고, 다음 과거 커서가 정상적으로 이전 날짜로 이동했다. 대차 수집 중간에 600행이 먼저 커밋된 것도 관찰했다. 최종 시점 두 자료 모두 과거 커서가 남아 있어 전체 기간 완료는 아니다. 나머지 요청 종목·종류는 순환 대기 중이며 완료했다고 기록하지 않는다.

공개 health의 release가 새 버전과 일치했다. 공개 투자자·프로그램 과거 조회 4건은 응답과 자료 범위가 정상이나, 해당 요청의 2024년 자료는 아직 수집 전인 사례가 포함된다. 성공 응답을 해당 과거 구간 확보로 취급하지 않는다.

근거: `work/remaining-v37/live-before.json`, `live-followup.json`, `live-final.json`, `verification.json`, `public-before.json`. 마지막 전 종목 작업 상태는 attempts 49,202·cursor 2,068·phase 3, 정상 collecting이며 인증 전역 backoff가 없다.

## 아직 완료되지 않은 조건

전 종목 자료의 마지막 페이지·404 보완, 주식분할 기준이 검증된 TTM·추가 지표, 실제 배당 기업행사 및 재투자, 실제 장중 체결·호가·복구·화면 검증은 남아 있다. 토스 구독 승인을 장중 수신으로 취급하지 않는다.

이번 변경은 과거 자료 수집과 표 생성 횟수 개선이다. 공개 인터넷 100동시 요청의 p95를 재측정하지 않았으며 기존 성능 목표 미달을 해소했다고 보고하지 않는다. 아버님의 실제 사용 과제도 아직 통과하지 않았다.
