## 원본 압축·중복의 제한된 관찰

활성 주식 원본의 소유 경로는
`/var/lib/docker/volumes/hannun-public-market_market-sources/_data/raw`입니다.
전체 `du`와 원본 해시를 반복하지 않고, 지정한 토스·네이버·FnGuide·DART 하위
디렉터리에서 각각 **최대 256개 디렉터리 항목의 파일 메타**만 읽었습니다.
다른 원천이나 다른 프로젝트의 내용은 읽지 않았습니다.

| 원천 | 표본 `.bin.gz` | 표본 `.json.legacy.gz` | 표본 `.json` |
|---|---:|---:|---:|
| 토스 | 92 | 53 | 111 |
| 네이버 | 86 | 71 | 99 |
| FnGuide | 102 | 71 | 83 |
| DART | 74 | 43 | 139 |

각 원천에서 256개 파일을 관찰했고 이 표본에는 `.bin` 파일이 없었습니다. 따라서
이 표본에서 `.bin`과 `.bin.gz`가 함께 남은 중복 후보는 발견하지 못했습니다.
**전체 원본이 압축됐다는 뜻도, 전체 중복이 0개라는 뜻도 아닙니다.** 파일 시스템
나열 순서의 제한된 표본이며 전체 시장·보고기간을 대표하는 확률 표본이 아닙니다.
내용을 읽거나 압축을 풀어 동일성을 확인하지 않았으므로 삭제 영수증으로 쓰지 않습니다.

현재 `raw_archive.py`는 원본 바이트 SHA, 메타데이터, legacy 봉투를 대조하는 reader를
가지며 `.bin`·`.bin.gz` 형식을 지원합니다. 저장 형식 지원 자체를 전체 자료의 실제
보존·독립 복원 통과로 바꾸지 않습니다. ZIP처럼 이미 압축된 원본의 절감률을 임의로
가정하지 않습니다.
