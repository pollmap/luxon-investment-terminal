# v56 — 실적·주가 지표 선택과 차트의 검증 기준 통일

공개 버전 `20261004-analysis-gates-v56`. 실제 공개 API를 먼저 대조하고 계산·원본·화면 데이터 계약을 보존했다.

## 확인과 변경

삼성전자·SK하이닉스·현대차의 EPS/OCF/EBITDA 가치평가 응답 9개를 실제 조회했다. 모두 HTTP 200이며 가격 시계열과 실적 자료가 있었다. EPS 비교선은 있지만 OCF/EBITDA는 기본 배수가 없고 과거 월말 표본이 24개 미만이라 기본 비교선은 생성되지 않았다. 이는 15배를 모든 지표에 강제 적용할 대상이 아니다. 현재 화면의 배수 입력은 유지한다. 단순 200 반환을 다중 지표 완성으로 보고하지 않는다.

지표 선택 목록은 기간 검증과 주식 기준 문자열 일치만 확인해, 실제 차트의 연간 기간·통화·종목·시장 기준 검사보다 느슨했다. 공통 함수로 두 구조 검사를 통일했다. 단독 분기, 다른 종목/통화/주식 단위, 공개 시점 미확인, 값 결측, 가격 없음 및 미확인 시장은 비교 가능으로 표시하지 않는다.

원자료 관측 범위(start/end)와 구조 검증을 통과한 비교 범위(comparison_start/end), 비교 가능한 연간/TTM, 기간 수를 별도 제공한다. 비교 기간 수는 연결/별도 및 각 기간이 합산된 구조 검증 결과이며, 선택한 5년 화면의 실제 가시 비교선 개수나 전 기간 확보율이 아니다. 발표 후 가격과의 일자별 연결·배수·표시 범위 판단은 계속 가치평가 API가 담당한다.

원주가가 추가·철회되면 지표 선택 응답도 무효화되도록 누락된 `bars:{code}:통합:raw` 의존성을 추가했다. 기존 재무 원문·계산 결과·정정 이력을 변경하지 않았다. BPS 등 원자료는 있어도 검증되지 않은 항목은 값 삭제 없이 비교 가능을 차단한다.

## 검증

관련 테스트 42개 통과. 최초 캐시 시험은 테스트 종목 fixture의 source_trace 누락으로 실패했고 fixture 계약을 보완한 뒤 통과했다. 실제 회계·차트 검증을 완화하지 않았다.

- 메뉴/차트의 기간·종목·통화·주식 기준·출처 일치.
- 관측된 기간과 비교 가능한 기간 분리.
- 데이터 없음과 가격 없음·기준 미확인을 구분.
- 원주가 추가 및 철회 후 같은 재무 자료의 메뉴 상태와 ETag 즉시 변경.
- 기존 결산·누적·TTM·정정·배수·표시 기간 회귀 검사.

공개 health에서 v56 확인. 대표 4종목의 지표 조회 HTTP 200. 삼성전자·SK하이닉스·현대차의 EPS/OCF/EBITDA는 비교 구조가 확인되며 현대차 EBITDA는 검증된 연간 자료 2개 기간(CFS/OFS 포함)으로 TTM이라고 표시하지 않는다. 네이버는 share-basis 미확인으로 비교를 허용하지 않는다.

근거: `work/remaining-v56/metrics-before.json`, `valuation-before.json`, `metrics-after.json`, `tests.xml`. 변경: `valuation_series.py`, `analysis_inputs.py`, `app.py`, `tests/test_metric_availability.py`, `DECISIONS.md`.

## 남은 완료 조건

추가 기업과 기간의 TTM·주식분할 기준, 배당 기업행사·재투자, 전 종목 전체 과거/404, 실제 장중 체결·호가·복구, 공개 인터넷 성능 및 실사용은 남아 있다. 이번 변경은 비교 가능 상태의 일관성을 보완했으며 미검증 자료를 자동 허용하거나 전체 완료로 처리한 것이 아니다.
