## 범위 변경

2026-10-04 사용자의 최신 요청에 따라 코넥스를 검색·순위·시장 선택·상세·종목별 자동 수집·실시간 구독과 완료 대상에서 제외했다. 코스피·코스닥의 기존 보통주·우선주 범위를 유지한다. 배당 재투자 비교 역시 이전 사용자 요청대로 제외한다.

공통 service_scope를 조회와 작업자에 적용했다. 기존 코넥스 활성 요청과 대기 작업도 실제 처리 대상에서 걸러낸다. 기존 원본·가격·작업 이력은 삭제하지 않으며, 코넥스 107종목 식별 정보를 excluded-konex-identities-20261004 원본 아카이브로 보존했다. 이전 코넥스 필터 링크와 저장 설정은 전체 시장으로 변환하고 다른 선택은 보존한다.
