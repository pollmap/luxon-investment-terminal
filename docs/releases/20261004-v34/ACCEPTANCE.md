# v34 전 종목 보완 지표의 변경분 조회

공개 배포: `20261004-incremental-enrichment-v34`. 기존 주소·웹 빌드·관심종목 설정 유지.

## 확인한 병목과 변경

운영 DB의 `enriched`는 30,973,125문자, `universe`는 38,270,351문자였다. 한 종목의 지표 갱신이 전체 enrichment 원본의 재조회·JSON 해석을 유발했다.

- 기존 전체 `enriched` 자료와 source_trace는 보존한다.
- `enriched-item:{code}`와 원본 revision을 연결한 상태를 추가했다.
- 작업자는 원본 행을 잠그고 전체 호환 자료·해당 종목 조회 자료·revision을 같은 트랜잭션에서 갱신한다.
- 조회는 종목별 revision을 대조하고 변경된 종목의 payload만 읽는다. 기존 읽기 캐시에서 제거된 종목도 제외한다.
- 원본과 파생 자료의 revision이 다르면 기존 전체 원본 조회로 복구한다. 오래된 파생 자료를 최신으로 사용하지 않는다.
- 기존 2,876개 종목의 파생 조회 자료 생성 완료(8.92초). 원본을 덮어쓰는 이관은 하지 않았다.

## 검증

- 관련 로컬 테스트 46개 통과. 갱신 즉시 반영, 변경 종목만 조회, 삭제 후 재생성, 이전 쓰기 경로 복구, 파생 저장 실패 시 원본 transaction rollback 검증 포함.
- 운영 수집이 `073110`을 갱신한 후 파생 조회는 해당 종목 payload만 읽었다. 전체 2,876개 원본 결과와 일치했고 revision도 일치했다.
- 같은 과정에서 변경분 읽기 134.04ms, 전체 호환 원본 읽기 1261.12ms. 단일 자료 읽기 비교이며 API 전체 또는 사용자 체감 10배 향상을 뜻하지 않는다.
- 공개 배포 활성화 및 health·삼성전자 요약·웹 응답 검사 통과. 수집 작업자를 중단하지 않고 검증했다.

## 공개 인터넷 성능: 아직 미달

이전과 같은 Windows PC·공개 주소·HTTP/2 한 TLS 세션·100동시 스트림. 검색어 10개와 종목 10개를 사용했다. 작업자·공유 VPS 부하는 정상 실행 중이다.

| p95(ms) | 첫 100회 | 반복 300회 | 1.6초 대기 후 100회 |
|---|---:|---:|---:|
| 검색 | 1596.49 | 852.54 | 2450.39 |
| 상세 요약 | 1700.15 | 1906.15 | 2189.35 |

오류 0/1,000. v33 반복 상세 1431.25ms보다 느린 결과여서 공개 성능 개선으로 판정하지 않는다. 검색 300ms·상세 500ms 목표는 여전히 미달이다. 내부 조회 감소는 검증됐지만 API 동시 처리·전체 목록 조합·VPS 부하·인터넷 구간을 계속 분리 측정해야 한다.

근거: `work/remaining-v34/backfill.json`, `incremental-verification.jsonl`, `public-http2.json`.

## 전체 완료와 분리

전 종목 전체 과거 자료, TTM·분할 범위 확대, 실제 배당 지급일·기업행사, 추가 지표의 실제 입력, 장중 체결·호가·복구 및 사용자 화면 검증은 이 배포로 완료되지 않는다. 실제 사용자 수행과 공개 성능 목표도 미완료다.
