# v40 작업 기록 — 공개 성능 재측정과 계측 수정

공개 실행 버전은 `20261004-share-dividends-v39a`를 유지한다. v40은 측정 도구와 검증 기록의 변경이며, 서비스 배포나 성능 목표 달성을 뜻하지 않는다.

## 계측 변경

`scripts/benchmark_market_http2.mjs`가 응답 헤더 도착(TTFB), 이후 본문 수신, 압축 전송량, 원점/엣지 캐시 상태와 요청별 표본을 각각 기록한다. Nginx HIT/STALE/UPDATING/REVALIDATED와 엣지 HIT의 Server-Timing은 현재 앱 처리시간 집계에서 제외한다. 캐시에 보존된 생성 요청의 처리시간을 새 요청의 처리시간으로 보고하지 않는다. 헤더의 생성 처리시간 자체는 클라이언트 총 지연을 설명하는 완전한 서버 지표가 아니다.

공통 계측 함수의 회귀 테스트 2개와 Node 문법 검사가 통과했다. 캐시 응답의 과거 처리시간 제외, 실제 0ms와 결측의 구분, p95 관측값 선택을 검사했다.

## 단독 공개 인터넷 시험

근거: `work/remaining-v40/public-isolated.json`. Windows PC에서 공개 HTTPS 주소로 HTTP/2 TLS 연결 하나, 동시 스트림 100개, 검색어 10개/종목 10개를 사용했다. 첫 구간 100회, 반복 구간 300회, 1.6초 대기 후 100회를 각 endpoint에 순차 실행했다. 다른 부하 시험과 겹치지 않았다. 이는 독립 TLS 연결 100개 또는 실제 브라우저 사용자 100명의 시험과 같지 않다. 총 1,000회 모두 HTTP 200·JSON 해석 성공.

| 구간 | 검색 p95 | 상세 요약 p95 |
| --- | ---: | ---: |
| 첫 구간 | 1,425.97ms | 1,410.59ms |
| 반복 구간 | 870.41ms | 1,418.73ms |
| 1.6초 대기 후 | 4,424.00ms | 2,182.85ms |

목표 300ms/500ms 모두 미달이다. 한 번의 네트워크 시험 값이며, 이전 1.91초와 조건이 완전히 일치하지 않아 개선율을 산출하지 않는다. 반복 구간은 전체가 캐시 HIT가 아니다. 검색 HIT 200/EXPIRED 100, 상세 HIT 140/EXPIRED 160이다. 순수 HIT 속도와 혼합 구간을 혼동하지 않는다.

상세 첫 구간의 헤더 도착 p95는 1,398.83ms, 본문 구간 p95는 52.10ms다. 두 p95는 서로 다른 요청에서 나올 수 있어 합산·차감하여 원인을 분해하지 않는다. 개별 짝지어진 표본을 후속 분석에 사용한다. 삼성전자 요약의 별도 실응답은 JSON 45,296바이트, gzip 4,353바이트였다. 크기 축소만으로 전체 지연을 해결할 근거는 없다.

## Cloudflare 시험의 한계

기존 Worker 경로 시험(`public-paired.json`)의 검색 500회는 모두 MISS였다. 검색 p95는 첫 구간 약 6.10초, 반복 약 13.47초, 대기 후 약 14.16초로 현재 경로에서 목표를 충족하지 않았다. 상세 시험은 500회 중 471회 클라이언트 20초 제한에 걸렸다. 상세 후반에는 별도 원점 시험이 겹쳤으므로 이를 통제된 원점 대비 성능 수치로 쓰지 않는다.

`public-paired-origin.json`도 해당 겹친 원점 시험이므로 최종 기준선으로 채택하지 않는다. 최종 기준선은 단독 `public-isolated.json`이다. 이 시험만으로 Cloudflare 일반 성능을 단정하거나 전체 웹 이전을 확정하지 않는다. 공개 주소·관심종목·브라우저 설정은 변경하지 않았다.

## 남은 작업

순수 캐시 HIT/만료의 요청별 TTFB·본문·앱 생성시간 대조, 원점 캐시 잠금/인터넷 경로 진단과 동일 조건 재시험이 필요하다. 가격의 1초 신선도 예산을 늘려 성능 통과로 처리하지 않는다. 요약 크기를 줄일 때는 기존 facts 기반 설명 소비처와 전체 재무 탐색을 보존해야 한다. 아직 축약 API나 프런트엔드 교체를 배포하지 않았다.

전 종목 과거 자료·404 보완, 다른 기업/기간의 검증된 TTM·분할 기준, 배당락일·기업행사·재투자, 실제 거래일 체결·호가·복구 및 화면 반영, 실제 사용자 과제도 미완료다. 이번 시험은 해당 데이터 수집을 완료시키거나 전체 서비스 완성을 검증하지 않는다.
