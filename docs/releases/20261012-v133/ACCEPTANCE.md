# 주식 장보기 v133 — 공간 보존·증분 검색·기업 자료 수집

2026-10-12 KST. 검증된 변경의 단계별 기록이며 전체 서비스 완료 선언이 아닙니다.

## 구현

- 검색 시세 버전 변경 때 30종목 이하의 변경 행만 조회합니다. 원래 호환 자료 변경, 삭제, 동시 쓰기, 대량 변경은 전체 조회로 복귀합니다. 기존 결과·정렬·가격 TTL은 유지합니다.
- 연결 획득·SQL·결과 수신·JSON·gzip·잠금 대기를 분리해 측정합니다. 연결 획득은 최초 연결과 pre-ping을 포함하므로 순수 풀 대기로 해석하지 않습니다.
- 재무 요약에 빠진 연간·반기 보고서를 보관된 DART 목록 원문에서 찾아 기존 XBRL 작업에 연결합니다. 회사·접수번호·공개일·제목·요청 URL·원문 SHA가 일치해야 합니다. 검토되지 않은 주식단위나 TTM을 자동 승인하지 않습니다.
- 기업행사 반복 수집에도 기존 공간 게이트를 적용합니다. 제한 중 수집·커서·최초 정리 쓰기를 보류하고 저장 자료 조회는 유지합니다.
