- 백엔드 v75의 API·worker 컨테이너 ID는 각각 `4532695a825f`, `4e29f782489c`로 이전과 동일하다. OpenAlgo ID `a43c43c8a79f`도 동일하다. 웹만 `5859f3abdb51`로 재생성했다.

## 백필 상태 스냅샷

2026-10-05 03:29 KST 운영 DB를 읽기 전용으로 점검했다. 대상은 2,766종목, 추적 대상은 종목 × 7개 거래자료 유형 19,362쌍이다. 마지막 페이지 수신·원천 빈 응답·목록 누락 분류까지 포함한 작업 종료 상태는 3,771쌍(19.48%)이며, 수집 커서가 남은 항목은 15,591쌍이다. 이 비율은 작업 메타데이터 종료 비율이지 과거 데이터의 완전성·기간 확보율이 아니다. 그 시점에 작업 오류 상태는 없었고 worker는 `collecting`이었다.

거래자료 종류별 마지막 페이지 수신: 가격·수정가격 각각 572종목, 투자자 310, 프로그램 387, 공매도 654, 신용 609, 대차 333. 프로그램 119종목, 공매도 83종목, 신용 62종목, 대차 63종목은 원천의 빈 응답으로 종료되었다. 토스 목록 누락은 각 종류에서 동일 1종목으로 분류된다. 원천 빈 응답은 그 자료가 공개적으로 없다는 뜻으로 확대 해석하지 않는다.

요청 계측은 worker 프로세스 관측이다. `/api/v1/stocks/all`은 이 worker 계측 목록에 없지만 이전 공개 기능 대조 문서의 대표 응답 증거가 있으므로, 이를 서비스 전체 미사용으로 단정하지 않는다. API와 앱 프로세스의 호출을 따로 대조해야 한다. 전체 스냅샷은 `current-backfill-audit-v76-20261005.json` (로컬 보존 자료: `../../current-backfill-audit-v76-20261005.json`)에 저장했다.
