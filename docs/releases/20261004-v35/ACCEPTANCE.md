# v35 메모리 압력과 공개 지연 구간 확인

배포: `20261004-memory-timing-v35`. 기존 공개 주소·화면 빌드 유지.

## 변경과 검증

- API 메모리 한도 도달 580회, swap 211,668,992바이트(약 202MiB)를 확인했다. OOM 종료는 없었다. 이 기록은 메모리 압력의 증거이며 지연 전체의 원인 증명은 아니다.
- API 한도를 896MiB에서 1,280MiB로 조정했다. 신규 서버·유료 서비스는 추가하지 않았다. 다른 프로젝트의 설정은 바꾸지 않았다.
- 앱 네 컨테이너의 한도 합계는 3,328MiB(3.25GiB)다. 기존 DB 1,024MiB·Redis 128MiB까지 포함하면 4,480MiB(4.375GiB)로, 최초 4GiB 목표보다 384MiB 높다. 서버 여유 메모리 약 1.5GiB를 확인한 뒤 조정했으며 DB나 수집 작업자의 한도를 임의로 낮추지 않았다. 장시간 운영의 메모리 회귀 검증은 남아 있다.
- 검색·상세 요약 응답에 `Server-Timing: app;dur=...`를 추가했다. 앱 진입부터 응답 헤더 생성까지이며 전송 완료·프록시·인터넷 시간을 포함하지 않는다. 자료 기준 시각이나 최신성을 뜻하지 않는다.
- 부하 검사에 앱 처리 p95와 공개 전체 p95를 각각 기록하도록 추가했다. 관련 테스트 35개 통과.

## 공개 100동시 요청

Windows PC → 기존 공개 주소, HTTP/2 한 TLS 세션, 100동시 스트림, 검색어·종목 각 10개. 첫 100·반복 300·1.6초 대기 후 100회. 원천 수집 작업자 정상 실행. 총 1,000회, 오류 0.

| 구간 | 검색 전체 p95 | 검색 앱 p95 | 상세 전체 p95 | 상세 앱 p95 |
|---|---:|---:|---:|---:|
| 첫 요청 | 1347.58ms | 353.97ms | 1623.46ms | 239.60ms |
| 반복 | 1117.06ms | 352.15ms | 1813.39ms | 230.41ms |
| 대기 후 | 1302.57ms | 412.31ms | 3005.51ms | 314.92ms |

공개 검색 300ms·상세 500ms 목표는 모두 미달이다. 개별 요청의 구성요소를 짝지어 분석하지 않은 백분위 수끼리 뺄셈하여 네트워크 지연을 계산하지 않는다. 다만 앱 처리만으로 공개 지연 전체를 설명할 수 없으므로 다음에는 프록시·전송·엣지 경로를 조사한다.

부하 후 API memory.current 365,109,248바이트, swap 0, memory.max 도달·OOM 0. 새 프로세스 초기 측정이므로 메모리 한도 조정만의 효과나 장기 안정성을 단정하지 않는다.

근거: `work/remaining-v35/public-http2.json`.

## 데이터 재감사

현재 DB를 재조회한 결과(`work/remaining-v35/data-audit.json`):

- 과거 일봉 작업 2,874개: collecting 2,690, ready 74, error 109, no_data 1. 작업 상태 집계이며 전체 원문 대조를 통과한 종목 수가 아니다.
- 자료 종류 전체에서 토스 404가 남은 종목 110개. 보완 일봉이 있다는 이유로 이 상태를 삭제하지 않는다.
- 기업행사 저장 1,155종목, 취소·정정 대체를 제외한 배당 이벤트 746건. 실제 지급 확인 0, 배당락일 0, 검증 완료 0이다.
- TTM EPS 원시 계산 결과 ready 행: 삼성전자 10, SK하이닉스 28, 현대차 32. 회계 기준·중복 기간을 포함할 수 있는 계산 행 수이며 검증된 연도 수나 전체 차트 범위가 아니다.
- 분할 기준 근거 구간: 삼성전자 2016-01-01~2026-06-30, SK하이닉스 2021-01-01~2025-12-31, 현대차 2021-12-31~2025-12-31. 이 밖으로 자동 연장하지 않는다.
- 실제 체결·호가 메시지 증거 저장 0행. 구독 승인으로 대신하지 않는다.

## 배당 원문 검토 결과

[삼성전자 공식 주주환원](https://www.samsung.com/global/ir/stock-information/shareholder-return/)은 2021-04-16 특별배당 지급 완료를 명시한다. 하지만 DB의 2020-12-31 보통주 배당 1,932원은 일반·특별 합산 금액이다. 특별배당 부분에 관한 근거를 합산 배당 전체의 지급 확정으로 사용하지 않았다.

[2024년 기말배당 공식 공시](https://www.samsung.com/global/ir/reports-disclosures/public-disclosure-view.84277/)는 주총 후 30일 이내 지급 계획을 설명한다. 이는 실제 지급일 증거가 아니다. 이번 검토로 배당 재투자 완료 행을 추가하지 않았다.

전체 과거 자료·404, TTM 분할 범위 확장, 기업행사·배당 재투자, 실제 장중 수신·복구·화면 검증, 추가 지표 실제 입력, 공개 성능·실사용 검증은 여전히 전체 완료 조건이다.
