# v47 — KIND 배당락과 실제 지급 이력 연결

공개 버전 `20261004-kind-dividends-v47`. v46 백엔드를 확장하고 기존 v45 프런트, 주소, DB 이력, 관심·설정 및 다른 VPS 서비스를 보존했다.

## 실제 자료와 구현

공식 KIND 문서 `20251126001158/99335.htm`은 현대자동차 **1우선주**의 중간(분기)배당락 적용일을 2025-11-27로 명시한다. 이 문서를 보통주나 다른 우선주의 근거로 사용하지 않는다.

`kind_dividends.py`에 엄격한 회사명·주식 종류·적용일 파서와 명시적으로 검토한 문서→현대차우(005385)→2025-11-30 배당 기준일 연결을 추가했다. 배당 기준일·금액·실제 지급일은 KIND 공시에서 추정하지 않고 기존 Hyundai IR의 해당 우선주 열 관측값에 의존한다. 근처 날짜를 자동 매칭하거나 T+2로 배당락을 계산하지 않는다. 현 단계는 검토된 한 문서의 연결이며 전 종목 KIND 자동 탐색이 아니다.

KIND 원본 바이트·해시와 별도 지급 근거를 보존한다. 동일 회사·종목·주식 종류·기준일·금액이 일치할 때 기존 `enrich_dividends`로 연결한다. 중복 배당 권리를 생성하지 않는다. 오류·스키마 변경 시 기존 정상 자료를 보존하고 독립 작업 상태에 실패를 기록한다. 일별 재확인과 실패 후 1시간 재시도를 사용한다.

`corporate_events.collect_events`의 DART 재시도 제한 이전에 호출하여 DART 일일 예산 소진이 독립 KIND 조회를 막지 않게 했다. 토스 인증·구독·호출량에는 영향을 주지 않는다.
