# v38 공식 기업 IR 배당 지급일 연결

공개 배포: `20261004-issuer-dividends-v38`. 기존 화면 빌드·공개 주소·사용자 설정과 DB 보존.

## 실제 원천과 구현

현대차 공식 IR 주주환원 페이지의 Dividend History 표를 검토했다.
https://www.hyundai.com/worldwide/en/company/ir/stock-information/shareholder-return-policy

표에는 보통주·우선주 계열별 금액, 기준일, 지급일이 있다. 배당락일은 없다. 이번 어댑터는 확인한 보통주 열만 `005380`에 연결한다. 우선주 코드를 접미사로 추정하거나 보통주 배당금을 복사하지 않는다. 다른 기업 전체가 자동 지원된 상태가 아니다.

- 검토한 표 제목 6개와 셀 수, 날짜·금액·중복 충돌을 검사한다. 형식이 바뀌면 기존 정상 자료를 보존하고 오류로 기록한다.
- 지급일이 아직 미래인 행은 지급 확정 근거로 사용하지 않는다.
- 공식 HTML은 원본 바이트와 해시로 보존하고 수집 시각을 기록한다. 공식 페이지의 원래 공개 시각을 알 수 없으므로 available_at은 이번 관찰 시각이다. 과거부터 알려졌던 자료라고 표시하지 않는다.
- 기존 DART 이벤트와 종목·주식 종류·기준일·금액·통화가 모두 일치할 때만 지급일을 연결한다. 독립된 지급일 근거를 field_evidence에 둔다.
- 기존 관찰 자료를 보존하고 날짜가 충돌하면 재투자를 차단한다. 배당락일과 기업행사 전체 확인 없이 coverage를 검증 완료로 승격하지 않는다.
- 기업행사 수집 경로에서 하루 간격으로 자동 확인한다. DART 조회·예산 검사 이전에 실행하므로 DART 일일 예산 소진이 이 공개 IR 수집을 막지 않는다. 실패 시 한 시간 후 재시도하며 DART 작업은 계속할 수 있다.

주요 파일: services/market_dashboard/issuer_dividends.py, corporate_events.py, tests/test_issuer_dividends.py.

## 검증

관련 테스트 17개 통과. 미래 지급일·보통주와 우선주 금액 분리·표 구조 변경·날짜 오류·충돌 금액·재조회 제한·수집 실패 시 보존·정확한 배당 연결을 검사했다.

공개 서버에서 실제 공식 페이지를 조회하고 원본을 보존했다. 22건의 과거 지급일 관찰 자료를 저장했다. 기존 현대차 배당 17건 중 16건이 정확히 일치하여 지급 상태가 announced에서 confirmed로 바뀌었다. 미매칭 이벤트는 임의로 채우지 않았다. 검증 완료 배당은 여전히 0건이며 모두 배당락일 확인이 필요하다.

공개 events API에서도 17건 중 지급 확인 16건을 확인했다. health의 새 release와 일치한다. 테스트 fixture를 이 실제 집계에 포함하지 않았다.

근거: work/remaining-v38/tests.xml, hyundai-ir.html, live-verification.json, public-verification.json.

## 남은 완료 기준

배당락일, 주식 종류별 기업행사·권리·분할·합병, 전체 기간의 사건 누락 검증과 배당 재투자는 아직 미완료다. 공식 IR 어댑터는 다른 기업으로 확대해야 한다. 우선주 배당 연결도 검증된 회사·종목 매핑이 필요하다.

전 종목 과거 자료·404, TTM 분할 기준 확대·추가 지표, 실제 장중 수신·복구·화면 검증, 공개 100동시 요청 성능과 실제 사용자 과제도 남아 있다. 이번 지급일 연결을 전체 배당 성과나 전체 서비스 완료로 보고하지 않는다.
