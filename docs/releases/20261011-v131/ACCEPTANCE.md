# 주식 장보기 v131 — 화면·시세 저장·회사 근거 연결

2026-10-11 KST. 대상 버전 `20261011-stock-shopping-v131`.

## 이번 변경

- 표시 이름을 주식 장보기로 변경했다. 기존 URL·관심종목·저장 키·설정 백업 형식은 유지했다.
- 시장 지수와 회사 요약을 압축했다. 선택 OHLC는 차트 아래, 초기화·상하한가는 추가 설정에 배치하고 VI·거래정지는 유지했다.
- 거래량 보조 시리즈의 가격선·마지막 값 라벨을 제거했다. 거래량을 가격 눈금처럼 읽는 혼동을 막고 정확한 수량은 차트 아래에서 읽는다.
- 모바일 목록 복귀의 18px 이동은 앱 복원과 브라우저 anchoring의 충돌이었다. 해당 영역의 자동 anchoring 및 브라우저 자동 복원 중복을 제거했다. 시장의 부분 응답에서 indices가 없어도 화면을 유지한다.
- 시세를 quote:<code>로 원자적으로 갱신한다. 원래 quotes는 보존하고 합성 조회로 기존 응답을 유지한다. 토스 200종목 배치, 상세·OpenAlgo·일별 지표 갱신을 연결했다.
- 정상 동일 시세의 첫 수신에서만 종목별 행을 만들며 과거 자료 시각을 바꾸지 않는다. 조회 API는 전환을 위한 쓰기를 하지 않는다.
- 원천 뉴스 종목 태그를 미검증 후보로 분리했다. 확정 회사 필터는 SQL limit/count 이전에 적용하며 뉴스 공동 등장을 사업 관계로 만들지 않는다.
- DART 저장 원문의 해시·발행회사·접수번호·제목·날짜를 대조하는 공시 검색 연결을 추가했다. 회당 4종목×20행, 체크포인트, 디스크 80% 이상 중단을 적용했다. 현재 공간 조건에서는 실제 공시 색인이 실행되지 않는다.
- 제외된 코넥스의 별도 선택·cursor 갱신 실행 분기를 제거했다. 대상 필터·기존 원본과 이력은 보존했다.

## 검증

- Python 통합 검증: 자료·범위 98개, 시세·상세·배포 115개 통과. JUnit 기록은 같은 폴더에 있다. 별도 담당 검증의 174개·90개와 겹치므로 이를 더해 고유 테스트 수로 세지 않는다.
- 실제 PostgreSQL 17에서 새 독립 schema에 4연결·44갱신 검사를 수행했다. 정상값 보존·부분 병합·종목별 revision 격리를 통과했고 시험 schema를 제거했다. 운영 테이블을 fixture로 바꾸지 않았다.
- Playwright fixture 30개 및 시장 후속 2개 통과. 1440px 차트 시작 244.98px, 390px 353.39px. 시장 첫 화면 PC 8행·모바일 3행. 실제 공개 데이터, 실물 기기, 200% 브라우저 확대를 대신하지 않는다.
- TypeScript 및 프로덕션 정적 컴파일 통과, 파일 74개 무결성·HTML 자산·PWA 검사 통과. 거래량 라벨 후속 수정 후 최종 정적 빌드를 다시 검사했다.
- Cloudflare 공개/차단/캐시 계약 32개 통과. TSX lint 오류 0, 기존 img 경고 1. Python 실행에는 기존 라이브러리 deprecation 경고가 있었다.

## 공간과 롤백

비활성 배포 v125~v127의 5,594개 파일을 원본별 해시와 외부 압축본으로 대조하고 v125 전체를 독립 복원했다. 검증 후 비활성 배포 3개 688,747,314B를 정리했다. 현재·최근 정상 2개·저장 읽기 의존성·다른 서비스를 보존했다. 이는 앱 배포본 복원이며 DB 전체 복원이 아니다.

정리 후 배포 전 `/`는 총 154,894,188,544B, 사용 145,981,730,816B, 가용 8,895,680,512B, df 표기 95%였다. 대량 수집·색인 재개 기준인 80% 미만에는 미달한다. 원본·DB·부분 복원 결과를 삭제하거나 전역 Docker prune을 하지 않았다.

순정 v130은 새 quote 행을 읽지 못한다. 최초 전환 전에 v130+호환 Store 두 파일만 포함한 별도 롤백 이미지를 만들고 network-none/read-only SQLite 검사를 통과하도록 배포 도구를 수정했다. 실패 시 API·worker에만 전용 compose override를 적용한다. 수동 롤백도 기록된 override가 필수다. 이전 DB로 자동 복원하지 않는다. 실제 배포 산출물 결과는 deployment 기록으로 대조한다.

## 공개 반영과 실제 응답

VPS API·worker와 정적 웹, Cloudflare 정적 웹을 v131로 반영했다. PostgreSQL·Redis·OpenAlgo 및 다른 서비스를 교체하지 않았다. 공개 `/health` 버전과 삼성전자·JYP 요약, 근거 검색 5개 요청을 확인했다. 미검증 뉴스가 확정 회사 코드로 반환된 결과는 0개였으며, 특정 회사의 검증된 근거가 없으면 빈 결과를 유지했다.

- 백엔드 패치 SHA256: `d642decf2f2a063b68aff1d340cbd6fa5bc3ff40c4b052670220b947fd5d94bc`
- 정적 배포 압축본 SHA256: `0c5fc1ebc712430a8b532bd60382b7cf095e36004911e0f4a54f4ab88d68c477`
- Cloudflare version: `83450bb0-7d1d-4eea-a3aa-0bb21a2f14fd`
- v130 호환 롤백 이미지가 실제로 빌드되어 사전 검사를 통과했다. 운영 장애를 강제로 일으키는 전체 롤백 시험은 수행하지 않았다.
- 공개 브라우저를 새 탭에서 다시 열어 주식 장보기 제목, 3개월 일봉 캔들, 오른쪽 호가, 차트 아래 OHLC, 거래량 가격 라벨 제거를 확인했다. 최초 기존 탭 새로고침은 도구 시간 초과였고, 새 탭 확인으로 복구했다. 현재 가격은 10월 8일 마지막 확인 가격으로 표시됐다. `public-samsung.jpg`가 실제 공개 화면이다.

## 공개 100연결 성능 — 목표 미달

동일 v131에서 호스트마다 독립 TLS 연결 100개, 검색어 10개·종목 10개를 사용했다. 각 경로는 첫 요청 100건·재사용 연결 300건·1.6초 후 100건이다. 두 호스트 합계 2,000건의 HTTP 오류는 0건이다. 연결 수립 시간은 별도 기록하며 아래 응답 p95에 합산하지 않는다. 재사용 구간에도 캐시 만료와 재계산이 포함된다. 수집은 운영 상태로 유지했으며 수집 중단 조건의 별도 시험은 이번에 하지 않았다.

| 경로 | 첫 요청 p95 | 재사용 구간 p95 | 1.6초 후 p95 |
|---|---:|---:|---:|
| VPS 검색 | 1,277.63ms | 472.23ms | 466.68ms |
| VPS 상세 요약 | 686.23ms | 503.70ms | 566.31ms |
| Cloudflare 검색 | 1,929.95ms | 1,558.80ms | 2,172.92ms |
| Cloudflare 상세 요약 | 862.38ms | 1,727.64ms | 1,580.65ms |

검색 300ms·상세 500ms 목표는 통과하지 못했다. VPS 재사용 구간의 앱 처리 p95는 검색 158.12ms·상세 173ms였다. 캐시/연결/인터넷 영향을 분리해 보며 단순 차감으로 네트워크 p95를 계산하지 않는다. Cloudflare 동적 경로를 기본으로 전환하지 않는다. 원본 결과는 `public-100connections.json`, 간단한 비교는 `performance-summary.json`에 있다. 이번 수치는 개선 전과 완전히 짝지은 시험이 아니므로 종목별 저장 변경의 속도 개선률이나 10배 성과로 보고하지 않는다.

공개 자산 검사에서 최초 curl의 리다이렉트 미추적으로 해시 불일치가 발생했다. 리다이렉트와 압축 해제를 적용해 다시 검사한 VPS·Cloudflare HTML/CSS 8개는 로컬 빌드 SHA256과 모두 일치했다. 검사 방법 문제였으며 공개 파일을 다시 바꾸지 않았다.
