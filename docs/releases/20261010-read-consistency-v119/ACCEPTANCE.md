# 주식담 v119 — 차트 조회·수집 현황 일관성

2026-10-10. v118의 최신 자료 갱신과 종목 주소 복원을 유지하고, 차트 중복 조회 및 수집 상태 병합을 수정합니다. 공개 반영 결과는 검증 후 아래에 추가합니다.

## 변경

- OpenAlgo가 정상 차트를 반환하면 공개 `/bars` 처리에서 전체 과거 이력을 미리 읽지 않습니다. 저장 메타데이터만 확인하고, 비활성·오류·기존 이력과 모순되는 빈 응답이면 기존 이력을 한 번 읽어 복구합니다. KRX/NXT·조정 기준·기간·집계 규칙은 유지합니다.
- 일반 기업자료 수집과 토스 거래자료 수집이 동시에 현황을 갱신할 때 같은 DB 트랜잭션에서 현재 값을 읽고 병합합니다. 없던 행의 동시 생성도 포함합니다.
- 검증된 토스 거래 기록을 일반 수집기가 다른 출처로 바꾸지 못하도록 했습니다. 오래된 관측이 새 기록을 덮는 경우와 공급자 변경 때 이전 공급자의 검증 필드가 따라오는 경우를 막습니다. 기존 Naver 자료를 토스 자료로 바꾸어 표시하지 않습니다.

## 로컬 검증

- 차트 관련 163개 검사 통과: 새 회귀 49개, 기존 114개. 기존 검사에는 API의 대상 테이블 무쓰기 검사 87개가 포함됩니다.
- 수집 현황 관련 58개 검사 통과: 동시 갱신·최초 행 생성·반대 쓰기 순서·정정·실패 날짜 보존·혼합된 과거 기록 처리.
- 정적 웹 빌드와 TypeScript 검증 통과. 화면 소스는 v118과 같으며 배포 식별자는 v119입니다.
- 이 결과는 고정 입력·SQLite와 빌드 검증입니다. 실제 PostgreSQL, 공개 화면, 공급자 수신은 별도 항목입니다.

## 이 배포로 완료되지 않는 항목

전 종목 과거 자료, TTM·주식분할·배당의 전체 입력, 실제 장중 체결·호가, 사용자 실사용, 공개 100동시 요청 성능 목표는 아직 통과하지 않았습니다. 백업의 독립 복원이 중단되어 운영 저장 테이블 전환과 원본 삭제를 실행하지 않았습니다. 원본·마지막 정상 자료와 기존 수집기를 보존했습니다.
