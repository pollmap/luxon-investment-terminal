# v134 — 공개 분석 기능 대조·배수 흐름·재무 근거 보존

작업 시작 2026-10-12, 통합 확인 2026-10-13 KST. REA와 FAST Graphs·Simply Wall St의 공개 기능을 대조한 구현입니다. 로그인·유료 화면이나 상용 내부 시스템 전체를 복구한 결과는 아닙니다.

## 변경

- 기업 분석에서 **실적·주가 / 배수 흐름**을 같은 차트와 응답으로 전환합니다. 선택 날짜·확대·가정과 공유 링크를 보존합니다.
- 서버가 검증한 실제 배수만 사용합니다. 실제 배수·선택 비교 배수·과거 대표 배수를 구분하며 결측 구간을 별도 시리즈로 끊습니다. 지표·주식 기준을 무시해 가격에서 배수를 다시 만들지 않습니다.
- 같은 종료일이라도 실제 시작일·빈도가 다른 실적은 보존합니다. 실제 회계기간의 양끝·연결/별도가 맞는 전년 자료만 증감률을 계산합니다.
- `GET /api/market/v1/securities/{code}/analysis/financial-questions?basis=CFS|OFS`로 회사 전체의 이익·영업현금흐름과 이익률을 같은 기간에 대조합니다. 펼칠 때만 요청하며 검증 불가·조회 실패는 가격 차트와 분리합니다.
- DART 기간 자료의 회사 ID가 정규화 테이블에만 붙고 화면용 스냅샷에서는 빠지는 결함을 수정했습니다. TTM 읽기 모델은 입력의 실제 기간·회사·공개일 근거를 보존하고 동일 기간의 근거가 더 강한 자료를 우선합니다. projection은 v15로 갱신하며 원본은 변경하지 않습니다.
- 검색 결과 최대 30종목의 필요한 필드만 읽는 compact 경로와 revision 대기 계측을 연결합니다. PostgreSQL JSON 경로의 Text 배열을 실제 서버에서 검증했습니다.
- 현재·미래 봉이 있다는 이유로 오래된 전일 종가를 정상으로 인정하던 등락률 결함을 수정했습니다. 해당 전일 근거가 없으면 등락률은 `null`이고 최신 가격·자료 시각은 유지합니다.

기존 `apps/web/next-env.d.ts` 변경과 복원 도구의 미커밋 변경은 이번 기능 커밋에 넣지 않습니다. 외부 의존성 추가, 공급자 연결 변경, DB 이전·원본 삭제·대량 수집은 하지 않습니다. 정적 빌드는 격리된 생성 디렉터리에서 수행하여 기존 생성 타입 파일 오류를 제품 소스 오류와 구분했습니다.

## 실제 자료와 남은 항목

삼성전자·SK하이닉스의 기존 공개 TTM 요약은 최신 2025-07-01~2026-06-30의 매출·영업이익·순이익 3행이었으나 회사 ID·공개일 근거가 비어 있었습니다. 해당 요약의 OCF 행도 없었습니다. 삼성전자 2025 연결 재무 원문에는 현금흐름 42행이 있었지만 실제 기간 문맥과 공개일이 화면용 자료에 없었습니다. **원문 숫자 존재와 검증된 동일 기간 비교 입력은 다릅니다.** 새 API에서 이를 0 또는 검증 완료로 바꾸지 않습니다.

회사·공개일·차원·현금흐름 입력이 확인되어야 실제 이익/현금흐름 비교가 활성화됩니다. CAPEX·FCF도 필요한 양쪽 취득 계정이 모두 확인될 때만 계산합니다. 새로운 수집과 전 종목 TTM·분할·배당·장중 수신·전체 복원·한국어 검색 품질·100동시 성능 목표는 이번 코드·fixture 통과로 완료 처리하지 않습니다.

## 배포 상태

후보 release는 `20261012-reference-analysis-v134`입니다. 공개 API/정적 자산/Cloudflare의 실제 반영·버전·숫자 대조는 배포 후 별도 기록합니다. 이 문서의 후보 빌드 통과를 공개 배포 완료로 사용하지 않습니다.
