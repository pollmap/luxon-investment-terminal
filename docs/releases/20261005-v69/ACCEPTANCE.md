# v69 — 반기 주식 기준과 TTM 연결

## 수정 및 근거

무분할 검토 구간도 공시·회계 기준·기간·회사·개별 종목이 모두 일치하는 명시적 단위 검토를 지원한다. 공개일이 검토 구간 뒤여도 공시의 단위 날짜가 구간 안임이 확인되면 연결한다. 다른 접수번호, 우선주, 회사, 잘못된 날짜, 중복 검토는 거부한다. 공개 시각과 가격 검토 구간은 늘리지 않는다. 조회 모델 버전은 11이다.

SK하이닉스의 2026년 반기 자본금 변동 설명은 이전 사업보고서를 참조하며, 주식 총수 표는 2003년 병합과 2026년 이익소각을 구분한다. 현대차의 보통주 액면금액·자본금·주식 수와 감소 내역을 기존 사업보고서 검토에 연결했다. 검토 구간은 두 기업 모두 2026-06-30까지이며, 우선주는 포함하지 않는다.

2026년 반기 EPS 주석의 당반기·전반기 3개월/누적 기간에는 개별 단위 검토를 추가한다. 이후 날짜의 시세까지 확인한 것으로 확대하지 않는다. 기존 근거는 `share-basis-before-v69:<code>`에 보존하고 새 근거에 연결한다. 원본 파일은 해시 대조 후 raw 저장소에 추가한다.

## 검증

관련 테스트 22개 통과: share_basis, split_units, eps_calculation, official_views. 명시적 근거가 있는 늦은 공시 연결, 다른 종목·회사·접수번호·잘못된 단위 날짜·중복 검토 거부, 기존 분할과 TTM 계산 포함.

실제 자료 적용 스크립트: `work/remaining-v69/apply_review.py`. 확인한 원문 위치·해시: `work/remaining-v69/sources.json`. 가격 조회 범위와 전체 서비스 완료는 별도 검증 대상이다.

## 실제 결과
2026-10-05 공개 API /securities/{code}/financials/per-share에서 SK하이닉스·현대차 모두 최신 TTM status=ready, 기간 2025-07-01~2026-06-30, input_count=24를 확인했다. 과거 CFS ready 기간 수도 각각 8→11, 4→7로 증가했다. 계산 근거 연결이며 최신 비교선의 가격 기준까지 완료한 것은 아니다. price_basis_status=requires_price_alignment를 유지한다. 삼성전자는 share_basis_required로 남는다.
공개 release=20261005-halfyear-share-basis-v69. 결과는 work/remaining-v69/analysis-after.json 및 public.json에 보존했다. 이전 근거 두 건과 원문은 삭제하지 않았다. 전 종목·전체 기간·장중·공개 성능·실사용 완료는 아직 아니다.
