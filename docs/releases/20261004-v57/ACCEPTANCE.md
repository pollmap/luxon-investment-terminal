# v57 — 공개 프록시 연결 재사용·엣지 버전 정리와 성능 재측정

운영 프록시 변경 v57. 앱 health 버전은 `20261004-analysis-gates-v56` 그대로이며 앱 코드를 새 버전으로 배포했다고 표현하지 않는다. Cloudflare의 RELEASE도 현재 백엔드 v56에 맞췄다. 엣지 배포 버전 ID `93deb527-933b-4d58-9a88-4d2128b51043`.

## 수정

이 서비스의 Nginx REST API route만 로컬 upstream 연결 재사용 풀로 전환했다. 유휴 연결 64개, 연결당 1,000요청, 유휴 60초이며 전체 동시 연결 수를 64개로 제한하는 설정이 아니다. 기존 HTTP/1.1 및 Connection 헤더 제거를 사전에 검사한다. 8210/8211 외 포트는 거부한다.

공유 Nginx 편집 잠금을 사용하고 원래 설정을 현재 release에 보관했다. nginx -t 통과 후 reload했다. 실패 시 원래 파일 복구 및 검사·reload 경로가 있다. 테스트 4개 통과. 다른 서비스 설정·WebSocket 경로·캐시 TTL·인증/쿠키 bypass·오류 상태 처리를 변경하지 않았다. 실제 before/after 파일로 변경 범위를 확인할 수 있다. 기반은 [Nginx upstream keepalive 공식 명세](https://nginx.org/en/docs/http/ngx_http_upstream_module.html#keepalive).

기존 Cloudflare RELEASE가 v25에 고정돼 있었다. v56으로 맞춰 같은 worker를 배포했고 바인딩과 배포 ID를 확인했다. 캐시 정책 테스트 2개 통과. 원천 가격 검증 시각을 포함한 최대 1초 예산은 유지한다. 오래된 가격을 더 오래 캐시해 성능 목표를 달성한 것처럼 만들지 않는다.

## 같은 공개 인터넷 시험

동일 Windows PC, HTTP/2 연결 1개에 100동시 스트림, 검색어 10개·종목 10개, endpoint당 첫 100회·연속 300회·1.6초 후 100회. 전후 각각 1,000회, 오류 0건. 독립 100명/TLS 연결 100개의 시험이 아니다.

| 대상 | 수정 전 p95 | 수정 후 p95 |
|---|---:|---:|
| 검색 첫 요청 | 1,360.21ms | 1,370.20ms |
| 검색 연속 | 870.32ms | 1,141.92ms |
| 검색 1.6초 후 | 2,963.48ms | 1,345.76ms |
| 상세 첫 요청 | 1,970.85ms | 2,246.70ms |
| 상세 연속 | 2,114.19ms | 2,124.54ms |
| 상세 1.6초 후 | 4,215.66ms | 2,197.87ms |

혼합된 결과다. 연결 재사용을 적용했다는 이유로 전체 속도 개선이나 목표 통과를 주장하지 않는다. 검색 300ms·상세 500ms 목표는 계속 미달이다. 앱 헤더 처리와 전송 완료를 구분했다.

Cloudflare 실시간 검색·요약 시험도 1,000회 오류 0건이지만 모두 엣지 MISS였다. 검색 연속 p95 1,712.16ms, 상세 연속 2,394.11ms였다. 현재 실시간 캐시 조건에서 Cloudflare 주소만 바꾸는 것이 해결이라는 결론은 근거가 없다.

별도 정적 지표 정의·health를 각 호스트에 100동시로 조회했다. 정적 정의는 Cloudflare HIT 100건, p95 532.65ms였다. 기본 정보 캐시의 동작을 확인한 것이며 실시간 검색 목표나 전체 UX 개선 증거로 쓰지 않는다. 엣지 RELEASE 변경 후 같은 기초 시험과 양쪽 health를 다시 수행했다. 재시험 정적 정의는 HIT 100건이지만 p95 2,180.11ms로 악화했다. health도 양쪽에서 느려졌으며, 한 번의 캐시 HIT 측정으로 안정적 속도 개선을 주장할 수 없다. 양쪽 health는 같은 v56 앱 버전이었다.

## 후속 판단

정적·확정 자료와 장중 가격을 분리해 전달하는 경로를 더 강화해야 한다. 현재 비용·공개 주소·사용자 저장값 보존 조건은 유지한다. 비교 가능한 100개 독립 연결 시험과 실제 브라우저 LCP/INP/CLS도 아직 완료 증거가 없다.

전체 과거 자료/404, 전 기업 TTM·주식 기준, 배당 기업행사·재투자, 실제 장중 수신 및 실제 사용 과제는 계속 남아 있다.
