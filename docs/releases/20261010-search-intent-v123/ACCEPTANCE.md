## 변경과 보존

시장 목록을 열기만 해도 전체 종목 검색 색인을 요청하던 동작을 바꿨습니다. 검색창에 포커스를 두거나 검색어를 입력했을 때 기존 공유 색인을 불러옵니다. 키보드 검색과 헤더는 같은 색인을 재사용합니다. 색인이 아직 없거나 실패했을 때에는 기존 검색 API로 결과를 제공합니다.

앱 변경은 `HeaderSearch`의 조회 활성 조건입니다. 새 의존성·화면 메뉴·데이터 지표는 추가하지 않았습니다. 백엔드 코드는 v122와 동일하며 다음 개선을 포함합니다.

- 투자자·프로그램·공매도 거래·신용·대차를 자료별 최신 시각으로 갱신하고, 한 자료의 실패를 다른 자료 전체로 전파하지 않습니다.
- JYP 신용융자·신용대주·대차 103일과 공매도 거래 203일을 10월 8일까지 연결한 조회 구조를 유지합니다. 원본과 이전 정상 관측을 보존합니다.
- 모바일 수급·대차/신용·공매도 기간 버튼은 3열×2행·최소 52px이며 글자를 줄바꿈하지 않습니다.

이전의 실제 거래 자료 수신·원본 대조 결과는 [v122](../20261010-active-refresh-v122/ACCEPTANCE.md)와 [v121](../20261010-trading-readmodels-v121/ACCEPTANCE.md)에 있습니다. 이번 검색 수정으로 재무·전 종목 확보 범위가 늘었다고 표현하지 않습니다.
