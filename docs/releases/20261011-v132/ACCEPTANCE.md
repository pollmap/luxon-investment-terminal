## 복원 실행과 최종 운영 보완

22:45 KST 독립 복원을 1회 실행했으나 약135.6초 후 DB 시작 전 중단됐다. 같은 coordinator의 읽기 재현에서 버전 확인 명령의 5초 제한 초과를 확인해 30초로 조정하고, 비밀값 없는 실패 단계·예외 코드 기록을 추가했다. 해당 집중 검사 6개가 통과했다. 전체 4시간·디스크 예산은 바꾸지 않았다.

후속으로 제품과 master의 선택 의존성에 Mako1.4.2·urllib3 2.8.0 하한을 적용하고 각 브랜치 잠금 파일을 갱신했다. 두 파일 모두 `uv lock --check`를 통과했다. - 공간: 주식 이미지의 실제 고유 레이어와 참조 확인이 시간 제한에 걸렸다. 현재·최근2개·호환 롤백을 뺀 후보를 새로 검증해야 하며, 태그별 표시 크기를 합산해 삭제하지 않는다. 대량 작업은80% 미만과 쓰기 검사 통과 전 재개하지 않는다.
- 성능: 새 부하 시험보다 revision의 연결 대기와 SQL·결과 수신 시간을 먼저 분리한다. 이미 두 시험을 수행했으므로 동일 조건·동일 가설의 반복 시험은 중단한다.
- 기업 자료: LG전자 원문 EPS 대조 불일치와 누락 XBRL 작업은 `INITIAL_SHARE_CANDIDATES.md`에 적었다. 미검증 주식 단위를 통과시키거나 EPS를 주식 수로 역산해 채우지 않는다.
- 실제 검증: 장중 체결·호가와 사용자 PC·휴대폰 조작은 아직 검증하지 못했다. 구독 승인·HTTP200·정적 자산 해시를 해당 검증의 대체 증거로 쓰지 않는다.
