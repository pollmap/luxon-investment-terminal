# 주식 서비스 이미지 읽기 점검

VPS의 Docker 이미지 목록과 실행·중지 컨테이너 참조만 확인했다. 삭제, prune, 서비스 변경, 볼륨 접근은 실행하지 않았다.

| 보존 대상 | 이미지 ID 앞 12자 | 확인한 참조 |
|---|---|---|
| v132 API | 9873c59c39ba | 현재 API·worker 실행 중 |
| v131 API | 8357523f7db5 | 최근 정상 릴리스 보존 |
| v131 quote rollback | 4903f168f390 | 호환 롤백 보존 |
| v130 API | 2a3973b0f524 | 최근 정상 릴리스 보존 |
| web | 8d06235ba8d0 | 기존 중지 web 컨테이너 참조, 여러 버전 태그가 같은 ID |
| OpenAlgo | f46ef529b0cc | 실행 중, 여러 버전 태그가 같은 ID |

`hannun-public-market-market-api`, `market-worker`, `market-web`의 이전 이미지도 기존 중지 컨테이너에서 참조 중이다. 중지 상태만으로 삭제 후보에 포함하지 않았다.

비활성 API 이미지 태그가 다수 남아 있으나 표시 크기는 공유 레이어를 포함한다. `docker system df -v`는 45초 제한을 넘겼고, 후속 이미지 목록 조회도 30초 제한을 넘겼다. 따라서 고유 크기·RootFS 포함관계·현재 compose의 전체 참조 대조를 완료하지 못했다. 태그 개수에 표시 크기를 곱해 회수 가능 용량으로 제시하지 않는다.

**이번 점검에서 증거가 충족된 삭제 후보는 0건이다.** 공간이 전혀 없다는 결론이 아니라, 안전한 실제 회수량을 확인하지 못했다는 뜻이다. 5분 점검 한도에서 종료했으며 Docker 조회를 자동 반복하지 않았다.
