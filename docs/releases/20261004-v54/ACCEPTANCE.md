# v54 — 전체 과거 수집 상태 대조와 재무 기간 스케줄 보완

공개 버전 `20261004-financial-fairness-v54`. 기존 토스 연결·공개 주소·프런트·원본·사용자 저장값을 유지했다.

## 실제 수집 상태

2,875종목 대상 작업자가 실제로 실행 중이며 큐 시도 49,752회, 종목 커서 2,324이었다. 이전 v49의 커서 2,302에서 진행한 것을 확인했다. 상태 파일만 보고 완료로 판정하지 않았다.

이는 개별 수집 작업 상태이고 전 종목 전체 데이터 완성 비율이 아니다. 큐 등록은 자료별 2,874건으로 전체 목록과 1건 차이가 있으며, 이 차이도 전체 완료로 보고하지 않는다.

404 보완의 기존 네이버 일봉은 원천 조회 창만 검증돼 있다. 추가 과거 수집 경로를 시험했으나 구 finance.naver.com 일별 페이지는 1·30·100페이지 모두 410, 공개 stock API 시험 경로는 400/409를 반환했다. 이 경로로 날짜를 더 확보했다고 주장하지 않는다. 검증되지 않은 새 수집기를 운영에 추가하지 않았다.

## 재무 수집 변경

재무 큐는 정렬된 최신 작업을 먼저 처리한다. 오류 작업의 재시도 시점이 도래할 때 미조회 과거 기간보다 계속 앞설 수 있는 구조를 보완했다.

미조회 기간을 먼저 처리하고, 누적 시도 기준 다섯 번째 차례는 기존 기간 재검사에 우선권을 둔다. 사용자 요청 기간은 항상 먼저 처리한다. 같은 우선순위에서는 기존 최신순을 유지한다. 기존 체크포인트에 시도 수가 없으면 1회로 취급하며, 이후 실제 조회 성공/실패 시 횟수를 기록한다. 호출 예산 도달은 실제 조회 시도로 추가하지 않는다.

원본·정정 이력·재시도 TTL·일일 호출 예산을 유지한다. 여러 키나 작업자를 추가하지 않았으며 기존 6,000회 설정을 높이지 않았다. 오늘 재무 큐는 rate_limited 상태다.

대표 실물 검사에서 삼성전자·SK하이닉스·현대차는 각각 작업 140개(ready 134/no_data 6)가 추적되고 이번 계획의 미시도 작업은 0개였다. 네이버는 ready 14개와 미시도 126개가 남아 있다. 원문 재무 수집 완료와 XBRL 주당지표/TTM 검증 완료는 다른 상태다. 2015년 이후 DART 제공 범위는 [공식 명세](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)로 재확인했다.

## 검증과 공개 반영

- 관련 재무 순서·전체 재무 수집·큐·기간 테스트 14개 통과.
- 미조회/재시도 차례, 사용자가 요청한 기간, 기존 체크포인트, 신규 작업의 최신순, 정정 후 이전 원본 보존 검사.
- 기존 정정 테스트는 새 재검사 순서에 따라 최대 다섯 차례 안에서 새 값과 이전 스냅샷 보존을 확인하도록 바꿨다. 정정 처리를 제거한 것이 아니다.
- 공개 삼성전자·네이버 재무 기간 API HTTP 200, health의 v54 및 토스 작업자 collecting 상태 확인.
- 오늘 새 DART 자료가 수신됐다는 증거는 없다. API 예산이 복구된 후 실제 미조회 기간의 진행을 추가 확인해야 한다.
