# 다중 지표 실적·주가 차트 — 구현과 검증

기준: 2026-10-03. 최종 앱 릴리스: `20261003-multi-metric-v25b`. 전체 서비스 완료 문서가 아니다. 기존 사용자 저장값·공개 주소·다른 VPS 서비스를 보존했다.

## 구현

- 지표 사전 12개와 종목별 실제 자료 상태를 연결했다. EPS·희석 EPS·OCF·FCF·EBIT·EBITDA·매출/주는 실제 XBRL의 계정·기간·단위·회계 차원으로 계산한다. BPS는 기존 자료를 유지한다.
- 조정 EPS·FCFE·FFO·AFFO는 없는 입력을 다른 지표로 채우지 않는다. 추가 기업 공시 매핑/계산이 필요한 미완료 범위다.
- EBIT는 법인세 차감 전 순이익과 이자비용을 우선 사용한다. 영업이익이나 포괄 금융비용으로 대체하지 않는다. EBITDA는 검증된 감가상각·상각을 추가한다.
- TTM은 금액을 먼저 합산하고, 기간 가중평균 주식 수로 나눈다. 서로 다른 주식 단위는 합치지 않는다.
- 가격은 필요한 기간만 읽는다. 비교 불가 값은 브라우저의 배수 입력으로 다시 생성하지 않는다.
- 지표·배수 전환 시 차트 객체, 확대 범위와 선택 날짜를 보존한다. 갱신으로 발생한 가상 crosshair 이벤트는 무시한다.
- 실적 표에 실제 값과 전년 대비 변화를 표시한다. 첫 5개 기간 외에 전체 실적을 열 수 있다. CSV는 차트와 같은 검증된 결과다. 최초에는 확인된 비교값이 있는 최근 날짜를 읽기 영역에 표시하고, 사용자가 최근 시세 날짜를 고르면 그 선택을 유지한다.
- 흰색/다크와 기존 큰 글씨를 보존했다. 차트 위 제목·선택창의 중복 여백을 줄였다.

## 실제 자료

`actual-metrics.json`은 운영 DB의 XBRL/가격을 읽어 계산한 증거이며 fixture가 아니다. `public-metrics.json`은 배포 후 공개 API 응답이다.

| 기업 | 실제 연간 자료 계산 | 가격 비교의 검증 범위 |
|---|---|---|
| 삼성전자 | EPS·희석 EPS·OCF·FCF·EBIT·EBITDA·매출/주 | IR로 확인한 2019-01-01~2026-06-30의 원주가/주식 단위. 각 지표의 실제 자료가 있는 기간만 연결 |
| SK하이닉스 | OCF·FCF·EBIT·EBITDA·매출/주 등 | 주식 단위의 가격 연결 검토가 남아 있어 비교선을 자동 생성하지 않음 |
| 현대차 | OCF·FCF·EBIT·EBITDA·매출/주 등 | 동일. 특히 EBIT/EBITDA 연간 확보 기간이 다른 지표보다 짧음 |

삼성전자 TTM 기본 EPS는 정정/회계 기준별 10개 검증 결과가 있다. 10개의 서로 다른 회계기간을 모두 확보했다는 뜻이 아니다. 기본 EPS의 5년 화면에서 현재 연결되는 주간 비교점은 16개이며 5년 전체 비교선 확보로 표현하지 않는다.

삼성전자 IR의 2018년 50:1 분할과 최근 8년 자본 변동, 2025/2026 자기주식 소각 기록을 원문 해시와 함께 보관한다. 2026-06-30 이후까지 자동 연장하지 않는다. 실제 분할을 가로지르는 일반적 조정 엔진과 전 종목 적용은 남았다.

OCF·EBITDA 등은 월말 표본 24개가 부족한 TTM 화면에서 자동 배수를 만들지 않는다. 사용자가 비교 배수를 입력하면 검증된 구간의 비교선이 표시된다. 주당 EBITDA 배수는 EV/EBITDA가 아니다.

## 토스·과거 자료·배당

`provider-audit.json`: 공개 시장 GET 20개 모두 실제 수신/원본 해시 기록이 있다. 모든 요청 옵션과 전 종목 완전 수집을 뜻하지 않는다. 키움·한투 실행 모듈은 없다.

`history-coverage.json`: 대상 2,875종목. 감사 당시 일봉 마지막 페이지 도달 74종목, 과거 페이지 수집 중 2,690종목, 404 미해결 109종목 등. 종목별 커서가 저장돼 자동 수집을 계속한다. 원주가 전 종목 배치는 아직 해당 단계에 도달하지 않았으며 일부 개별 종목 원주가만 저장돼 있다.

`data-gaps.json`: 자료별 404 대상 합집합은 코넥스 107개, 코스피 분류 3개다. 일부 코스피 항목은 펀드 X클래스로 보이며 종목 범위 재검토가 필요하다. 이름만으로 영구 삭제하거나 원천 미제공으로 확정하지 않았다.

삼성전자 배당 문서 29건은 확보했지만 배당락일 확인이 부족하고 실제 지급 확인은 0건이다. 배당 재투자 성과를 완료로 표시하지 않는다. 토스 스트림은 새 연결의 체결·호가 구독 승인까지만 확인했다. 토요일 휴장 중이므로 새 장중 이벤트·단절 후 장중 복구 증거는 없다.

## 검증과 운영

- 관련 Python 테스트 123개 통과. TypeScript 및 Next.js 운영 빌드 통과.
- 공개 주소에서 차트 전환·날짜/객체 유지·비교 불가 처리·1024/1280/1440/1920px 6개 브라우저 테스트 통과.
- 공개 주소에서 다크/더 큰 글씨, CSV 산식·값 일치 2개 추가 테스트 통과.
- 마지막 여백 조정 후 로컬에서 4개 화면 폭과 다크/더 큰 글씨 재검증 5개 통과.
- 최종 v25b 공개 배포 후 실제 지표 전환·선택 날짜 유지, 다크/더 큰 글씨 2개 회귀 검사 통과. 공개 상태 조회의 버전도 v25b와 일치한다.
- 실제 200% 브라우저 확대 및 아버님 직접 사용은 별도 미검증이다.
- 백업 `market-20261003T125447Z.dump` 553,011,486바이트. 별도 검증 DB에 복원하고 테이블 6개를 확인한 후 검증 DB를 제거했다.
- 운영 앱은 `/srv/services/korea-stocks/current`의 버전 전환 방식으로 반영했다. 앱 되돌리기가 DB를 과거 백업으로 덮어쓰지 않는다.
- 주식 서비스 Nginx 파일만 백업 후 HTTP/2와 캐시 미스 대기 1초를 적용했고 `nginx -t` 후 reload했다. 다른 앱 컨테이너를 재시작하지 않았다.

## Cloudflare와 성능 판정

별도 시험 주소 `https://korea-stocks-edge.lch68-workers.workers.dev`를 배포했다. 기존 공개 주소는 변경하지 않았다. 정적 파일·검색 색인·확정 재무를 캐시하며 현재가 포함 응답은 원점 검증 시각부터 최대 1초다. 호가·체결·스트림·오류는 캐시하지 않는다.

Workers 간 진행 중 I/O 공유 실험은 실제 부하에서 오류가 확인돼 제거했다. 요청 병합은 원점에서 유지한다. `public-http2-final.json`은 이 폐기한 실험의 기록이며 최종 배포 성능으로 인용하면 안 된다. 최종 재측정은 `public-final-transport.json`을 따른다.

공개 100동시 부하의 캐시 적중/미적중/만료와 전송 방식에 따라 지연 차이가 컸다. 최종 HTTP/1.1 동일 조건의 혼합 검색/종목 100동시 요청에서 원점 warm p95 검색 1,511.57ms·요약 1,735.56ms(오류 0), Cloudflare warm p95 검색 3,831.32ms·요약 6,451.15ms였다. Cloudflare 전체 시험 1,000요청 중 시간 초과 4건이 있었다. 목표 검색 300ms·상세 500ms를 안정적으로 달성하지 못했다. Cloudflare 주소로 주 서비스를 자동 전환하지 않았다. 10배 개선이나 전체 완료를 주장하지 않는다.
