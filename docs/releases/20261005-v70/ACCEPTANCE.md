# v70 — 삼성전자 최신 TTM과 응답 캐시 수정

## 실제 입력 연결

삼성전자 2026년 반기 보고서 `20260814003699`의 당반기 보통주 EPS 주석을 확인했다. 2026-01-01~06-30 누적, 04-01~06-30 단독 기간의 주식 단위를 기존 2018년 분할 이후 검증 기준에 연결했다. 기존 보고 숫자는 수정하지 않았으며 별도 주식 기준 검토만 추가했다. 검토 날짜는 2026-06-30을 유지한다.

반영 전에 실제 원천 입력으로 최신 CFS TTM이 계산되는지 검사했고 통과했다. 기존 근거는 `share-basis-before-v70:005930`에 보존했다. 원문과 해시는 `work/remaining-v70/sources.json`, 적용 스크립트는 `apply_review.py`에 있다. 전반기 누적 EPS의 대조 실패 항목을 이번 작업으로 승인하지 않았다.

## 응답 캐시 오류 수정

`financials/per-share`의 응답 캐시가 official·회사 식별자만 감시하고 share-basis 변경은 감시하지 않았다. 내부 계산 모델이 갱신돼도 사용자에게 이전 상태 또는 304가 반환될 수 있었다. 주식 기준을 의존성에 추가하고 응답 키를 변경했다.

관련 검사 41개 통과. 실제 API 요청을 통해 미검증→검증→철회 시 응답 상태와 ETag가 갱신되는지 검사했고, 변경 없는 재요청은 304를 유지했다. 기존 분할·TTM·조회 모델 검사도 통과했다.

## 완료 구분

대표 기업의 최신 TTM 계산과 현재 주가 비교선은 별개다. 주식 단위 검토는 2026-06-30까지이며 이후 가격을 자동 승인하지 않는다. 전 기업·전체 기간·실제 장중·전 종목 과거 자료·배당 정보·공개 성능·실사용 조건은 계속 남아 있다.

공개 검증: release=20261005-ttm-response-revision-v70. 삼성전자·SK하이닉스·현대차 모두 frequency=ttm 응답에서 2025-07-01~2026-06-30 계산값과 status=ready를 확인했다. 원값·분자·기간 가중 주식 수·공개일은 work/remaining-v70/public.json에 저장했다. 세 종목 모두 price_basis_status=requires_price_alignment는 유지한다. 서버 재배포 없이도 이후 주식 기준 변경이 캐시 무효화에 반영된다.
