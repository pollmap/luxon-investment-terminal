# v48 / v48a — 기업행사 원본 재검증과 배당 표 혼합 수정

최종 배포 버전 `20261004-events-parser-v48a`. v47의 KIND 근거와 기존 프런트·공개 주소·데이터 이력·다른 VPS 서비스를 유지했다.

## 확인한 병목과 수정

운영 저장소 감사에서 파서 버전이 없거나 처리가 끝나지 않은 기업행사 원본 87건을 찾았다. 일부는 자회사 자료·API 오류 원본이므로 모두 새 배당 자료로 계산하지 않는다. DART 예산 소진 또는 재시도 대기 시 이미 저장된 ZIP도 공시 목록 갱신을 먼저 요구하여 재해석이 막혔다.

`corporate_events.collect_events(..., archive_only=True)`를 추가했다. 원본 해시·ZIP 검증 후 기존 공시 목록의 문서만 처리하며 API 호출·기업 코드 조회·공시 목록 갱신을 하지 않는다. 원본이 없으면 건너뛰고, 캐시된 API 오류를 영구 미제공으로 승격하지 않는다. 재시도 대기 중에는 이 경로를 자동 사용한다. 공시 목록·수집 커서·재시도·기존 조회 시각은 보존하고 로컬 재검증 시각은 별도 기록한다. 정상 공급자 조회가 성공한 경우에만 이전 오류와 재시도 상태를 해제한다.

v48 실제 재처리에서 51종목 63문서를 검증했고 추가 공급자 호출은 0건이었다. 원본·공시 목록은 보존했으며 변경 전 작업·이벤트 상태는 별도 DB 백업 키 `corporate-events-replay-backup:v48`에 저장했다. 해당 서비스 작업자만 중지하고 finally에서 재시작하여 중복 쓰기를 방지했다. 다른 서비스와 웹 조회는 유지했다.

## 원문에서 발견한 파서 오류

JW중외제약(001060) 정정 공시 `20260311802453`와 DB하이텍(000990) 공시 `20260223800735`의 우선주 부속표가 본문 표에 섞였다. 부속표의 마지막 열인 배당 총액을 주당 배당금처럼 읽어 `Conflicting share-class dividends`가 발생했다. 정정 전후 비교표 역시 선언값과 혼동할 수 있었다.

v48a 파서는 번호가 있는 주당 배당금과 배당기준일을 가진 본문 표를 먼저 분리한다. 정정 비교표와 우선주 부속표는 본문 필드로 읽지 않는다. 본문 후보가 복수이면 오류로 남기고 임의 선택하지 않는다. 파서 버전은 `dividend-dates-v3`이며 저장 원본 재처리 경로로 확장된다.

## 검증

- 관련 배당·분할·분석 회귀검사 최종 42개 통과. 합성 테스트는 실제 배당 지급의 증거가 아니다.
- 실제 저장 배당 공시 752건의 읽기 전용 dry-run: 파싱 오류 0건, 필수값 미확인 4건은 검토 대상 유지.
- JW중외제약 수정 후 주당 650원·기준일 2026-04-01. DB하이텍 주당 810원·기준일 2026-03-10·지급 예정일 2026-04-23. 예정일은 실제 지급 확인으로 바꾸지 않는다.
- 현대차우 v47 검증 배당 1건과 기존 22행, 전체 coverage=false를 v48 공개 API에서 확인했다.
- 재처리 이후 작업자 상태 running 확인. 실제 실행 결과·공개 확인은 `work/remaining-v48`의 결과 파일을 기준으로 삼는다.

## 아직 통과하지 않은 항목

이 수정은 자료를 새로 확보한 것이 아니라 저장 원본의 해석·처리 병목을 고친 것이다. 전 종목 배당 지급·배당락·기업행사 전체 확보와 재투자, TTM/분할, 전체 과거·404, 실제 장중 체결·호가 수신, 공개 100동시 성능, 화면 및 아버님 실사용은 남았다. 752건 dry-run 성공으로 전체 공시 수집이나 실제 지급 검증을 완료 처리하지 않는다. 공개 성능은 재측정하지 않았으며 기존 미달 상태다.
