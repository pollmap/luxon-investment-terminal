# v66 — 변경 없는 거래 자료의 재처리 제거

## 변경

토스 거래 자료의 입력 시계열 버전·행 수·상태와 마지막 성공한 출력 버전을 대조한다. 모두 같으면 전체 이력 조회와 정규화 JSON 재작성을 생략한다. 수신 시각과 원본 보존은 기존 수집 경로에서 계속 처리한다.

행 수가 같은 값 정정, ready/stale 전환, 다른 작업의 출력 변경은 다시 처리한다. 중간 저장 실패에는 성공 표시를 남기지 않아 다음 응답이 같더라도 복구한다. 조회 API와 원본·과거 자료를 삭제하거나 축약하지 않는다. 내부 `toss-projection:*`에 재처리·생략 횟수와 처리 시간을 기록한다.
