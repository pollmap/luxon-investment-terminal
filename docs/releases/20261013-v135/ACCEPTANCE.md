# v135 — 기존 재무 총액 연결과 공식 휴일 전일 종가

2026-10-13 KST. 프런트엔드 v134의 공개 분석 기능을 유지하며, 실제 자료 검사에서 드러난 두 입력 경로를 보완합니다. 새 공급자·새 수집·DB 이전·원본 삭제는 없습니다.

## 변경과 근거

- 회사 전체 비교에 기존 `fundamental-metrics-v4`의 검증된 **numerator**를 연결합니다. 주당값·주식 수를 곱해서 금액을 만들지 않습니다. 회사·연결 기준·KRW·실제 TTM 기간·차원·공개일·원문 SHA·입력 사실 ID·계산 버전이 맞는 OCF·매출·FCF만 사용합니다. EPS의 보통주 귀속이익을 회사 전체 순이익으로 바꾸지 않습니다.
- `financial-questions-v2`는 계산 기간과 원문 문맥을 구분하고, 공개 응답 캐시에도 버전을 반영합니다. 주당값·주식 수를 바꿔도 회사 금액이 바뀌지 않는 회귀를 포함합니다.
- 공휴일로 이전 평일에 봉이 없으면 저장된 토스 한국 장 일정의 SHA·공식 URL·날짜 순서·KST 세션·정확한 previous/nextBusinessDay 관계로만 전일 종가를 인정합니다. 오래된 봉·현재 봉·수집 시각은 휴장 증거가 아닙니다. 달력 회수·변경·중간 개장일 충돌 시 캐시가 갱신됩니다.

## 통합 전 실제 자료 대조

저장된 삼성전자 분석 키의 최신 3행을 READ ONLY로 읽어 새 순수 계약에 적용했습니다. 2025-07-01~2026-06-30 매출 `485272032000000`원과 OCF `196729338000000`원을 반환합니다. 순이익·CAPEX·관련 비율은 null이며, 2025년 FCF는 `period_mismatch`로 최신 구간에 섞지 않습니다. 응답 상태는 **partial**입니다. 해당 금액은 보존된 계산 결과와의 일치 확인이며, 모든 입력 원문을 이번 실행에서 다시 계산한 전수 검증은 아닙니다.

실제 보존 장 일정 원문을 사용한 helper 검사에서 10월 12일의 전 거래일 10월 8일은 인정하고, 잘못된 10월 2일과 명시 휴장일 10월 9일은 거부했습니다. 공급자 호출·DB·시세 쓰기는 0건입니다.
