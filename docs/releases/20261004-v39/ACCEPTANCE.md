# v39 우선주 배당의 종목별 분리와 공식 원문의 이상 날짜 검토

## 식별과 범위

- 배당 원문: https://www.hyundai.com/worldwide/en/company/ir/stock-information/shareholder-return-policy

현재 주식 종류의 코드 연결은 검토한 4종목의 명시적 등록표다. 전체 우선주 회사 식별을 해결한 것은 아니다. 특히 DART corpCode가 보통주 코드만 제공해 다른 우선주의 기업 자료가 비어 있는 경로는 후속 작업으로 남아 있다.

## 변경

각 종목은 공식 배당표의 자기 열을 읽는다. 2025-02-28 기준 보통주 6,000원, 우선주 1/2/3계열 6,050/6,100/6,050원을 실제 저장 결과에서 대조했다. 지급일은 2025-04-18이다. 우선주에 보통주 금액을 복사하지 않는다.

하나의 공식 페이지 조회로 확인된 4종목에 분배하고 하루 단위로 재확인한다. 목록의 종목 이름이 등록표와 다르면 그 종목은 수집 대상에서 제외한다. 요청한 종목 자체가 불일치하면 오류로 기록한다.

DART 이벤트가 없는 종목에도 공식 배당 이력을 이벤트로 저장한다. 기존 같은 종목·주식 종류·기준일·통화 이벤트가 있으면 새로운 권리를 중복 생성하지 않는다. 다른 DART 금액을 공식 표의 값으로 덮어쓰지 않는다. 원문과 과거 관찰 근거는 보존한다.

공식 표에서 2018-06-30 기준일에 지급일 2019-08-14가 적힌 행을 발견했다. 실제 지연인지 오기인지 확인하지 못했다. 기준일보다 365일을 넘겨 지급한 행은 재검토 후보로 보존하고 자동 지급 확인에서 제외한다. 이는 서비스의 품질 검토 규칙이며 법정 지급기한을 뜻하지 않는다. 이전 자동 확인은 requires_review로 철회하고 이전 관찰을 별도 리뷰 저장소에 보존했다. DART 원본 사실은 변경하지 않았다.

## 검증

관련 테스트 20개 통과. 주식 종류별 열·금액·일자, 정확한 종목 이름 검사, 한 번의 조회로 분배, 재조회 중복 방지, 이상 날짜 후보 보존과 이전 자동 확인 철회를 검사했다.
