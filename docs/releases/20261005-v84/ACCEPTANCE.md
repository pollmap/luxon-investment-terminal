# v84 — 현재 종목 범위 밖 백필 이력 분리

## 변경

현재 KOSPI·KOSDAQ 목록에서 빠진 코드의 과거 Toss 백필 상태가 현 종목의 미해결 오류로 계속 집계되고 있었다. 원본 가격·거래자료와 페이지 커서를 삭제하지 않고 작업 메타데이터를 `out_of_universe`로 격리한다. 이 상태는 상장폐지 판정이 아니며, 코드가 서비스 목록에 다시 들어오면 작업 상태를 `queued`로 되돌리고 기존 커서를 보존한다.

## 검증

- `tests/test_toss_backfill.py`: 52 passed.
- Ruff `F`/`I001`: passed.
- v84 배포에서 API·worker만 교체했다. Postgres, Redis, web, OpenAlgo 컨테이너는 유지됐다.
- 공개 `/api/market/v1/health`: HTTP 200, release `20261005-universe-scope-backfill-v84`, KOSPI·KOSDAQ 2,766개.
- 배포 smoke: 삼성전자 검색·상세 API와 기존 웹 페이지 정상 응답.
- 백필은 `collecting`을 유지하고 attempts 54,594 → 54,612로 증가했다. 현재 범위 안의 남은 오류는 `001940` 공매도 `ConnectTimeout` 1건이다.
- 과거 범위 밖 작업 상태 640건을 이력으로 보존하고 격리했다. 자료 행·커서는 삭제하지 않았다.

실제 상태 스냅샷은 `backfill-scope-v84-20261005.json` (로컬 보존 자료: `../../backfill-scope-v84-20261005.json`)이다. 이 스냅샷은 현재 작업 메타데이터만 요약한다. 2,766개 전체 과거 자료의 확보·정합성을 증명하지 않는다.
