2. **이전 거래량 출처 형식:** v91 이전에 저장한 토스 일봉 거래량의 원본 봉투에는 가격 단위와 수집 시각이 있었습니다. 공개 조회에서 실제 해당 종목·일봉·통합·주 단위인 경우만 `주 / 거래일 / volume`으로 정규화합니다. 거래량·원본 URL·문서 해시·수집 시각과 저장한 원본은 보존합니다. 다른 공급자·종목·분봉을 재분류하지 않습니다.
