# v63 — 우선주 회사 정보·주주 표의 실제 연결

## 변경

기존 검증된 발행회사 연결 4종목(삼성전자우·현대차우·현대차2우B·현대차3우B)에 회사 소개와 회사 공시 주요정보 조회를 연결했다. 수집기가 우선주 자체에 기업 정보를 복사하기를 기다리지 않고 발행회사 읽기 모델을 사용한다.

공유 허용 구역은 최대주주·소액주주·최대주주 변동·임직원·감사인·타법인 출자다. 개별 주식 종류는 원천 행의 보통주/우선주 표시를 보존한다. 배당·발행주식·자사주는 자동 공유하지 않는다. 기존 종목별 배당 자료·EPS·가격·원본을 보존한다. 발행회사 원본 정정이 공개 상세 캐시를 무효화하도록 의존성을 추가했다.

## 검증과 공개 반영

- 관련 회귀 테스트 40개 통과. `work/remaining-v63/tests.xml`.
- 공개 버전 `20261004-company-facts-v63`. 기존 프런트엔드 BUILD_ID `nW8ejb3VHXWos1cxqiBbZ` 유지. 기존 공개 주소와 DB 볼륨 보존.
- 4종목 공개 회사 조회 200. 삼성전자우 주주 27행, 현대차 우선주 각각 20행. 회사명·공시 연도·구역별 공유 여부를 기록했다. `work/remaining-v63/public-profiles.json`.
- 실제 공개 브라우저에서 삼성전자우 기업 분석→주주→최대주주와 특수관계인 펼치기 확인. 보통주/우선주 종류, 기초/기말 보유, 지분율이 표로 표시된다. 가격 201,500원은 우선주 독립 가격이다.

## 범위와 미완료

4종목 자료 연결 진전이며 새 4종목이 전체 완료된 것은 아니다. 다른 누락 종목의 발행회사 연결, 전 종목 과거 수집·404·TTM EPS·분할, 실제 장중 수신, 공개 성능 목표와 실사용 검증은 남는다. 배당 재투자 비교는 사용자 요청으로 완료 조건에서 제외됐다.

LG전자·LG화학·삼성전기 공식 주식정보 페이지를 조사하고 HTML을 보관했으나, 해당 조사만으로 전체 누락 코드의 발행회사 관계가 검증된 것은 아니다. 이름 접미사만으로 연결을 확대하지 않았다. `work/remaining-v63/identity-source.py`, `lge.html`, `chem.html`, `sem.html`. LG화학 응답은 리다이렉트 HTML이므로 검증된 주식정보 본문으로 취급하지 않는다.
