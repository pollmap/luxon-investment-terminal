# v46 — 현재 거래량·거래대금의 기준일 혼합 수정

공개 버전 `20261004-daily-metrics-v46`. v45 프런트 빌드를 유지한 백엔드 수정이며 기존 저장 자료·주소·관심·설정·다른 서비스를 보존했다.

## 확인한 문제

태양3C(052960)의 현재 가격은 2026-10-02였으나 거래량 1은 2026-09-27에 수집된 기준일 미제공 integration 사실이었다. 2026-10-02 일봉에는 원천 거래량 0이 있었다. 이 둘을 동일 날짜·시장 자료로 단정하거나 한쪽을 다른 값으로 덮어쓰지 않는다.

기존 병합은 enriched facts가 최신 목록 facts를 무조건 덮어썼다. 전 종목 감사에서 화면에 거래량이 있던 2,859종목 중 2,760종목은 선택된 fact의 period가 기준일 미제공이었다. 최신 종목 목록에 같은 거래일 값이 있는 경우에도 이 오래된 상세 사실이 우선했다.

## 구현

`quote_metrics.py`를 추가하고 `app.py`의 공통 검색·순위·상세 읽기 모델에 연결했다. 표시 가격의 한국 거래일과 같은 날짜인 거래량·거래대금 fact를 상세 → 목록 facts → 목록 원천 값 순서로 선택한다. 날짜 비교는 한국 시간대로 하며 UTC 날짜 문자열 절단을 사용하지 않는다. 실제 0과 결측은 다르게 유지한다.

날짜가 없거나 다른 날의 값밖에 없으면 현재 수치는 null이며 availability_reason을 기록한다. 과거 사실과 원본을 저장소에서 삭제하거나 수정하지 않는다. 일봉 거래량을 실시간 누적 거래량으로 바꾸어 쓰지 않는다. 수집 시각을 자료 기준일로 사용하지 않는다. 주가·재무·배당 계산에는 변경하지 않았다.

이 수정은 기준일 선택을 고친다. 원천별 KRX/NXT/통합 범위 검증 전체를 완료했다는 뜻이 아니며 기존 source_trace의 시장 범위를 유지한다.

## 검증

관련 테스트 57개 통과, 실패 0. 오래된 기준일 미제공 상세값이 같은 날 실제 0을 덮어쓰는 사례, 날짜 미확인 값의 null 처리, 같은 날 유효한 상세값 우선, UTC→KST 날짜 전환, 기존 조회 캐시·검색·순위·수급·단위 회귀를 포함한다.

배포 전 전체 2,875종목 dry-run에서 현재 거래량 가능 2,768종목이었다. 삼성전자·SK하이닉스는 날짜가 있는 목록 값으로 재연결되고 태양3C·네오펙트는 기준일 미확인 값을 현재 거래량으로 표시하지 않았다. 이는 신규 데이터 수집 수가 아니다.

공개 health 버전 v46와 실제 상세 요약을 확인했다. 삼성전자 현재 거래량 16,915,343, 거래대금 3,141,812,000,000원은 기존 같은 거래일 원천값으로 유지됐다. 태양3C 현재 거래량은 null, 가격 3,515원은 유지됐다. 전 종목 입력 데이터를 보존한 후 공통 읽기 모델만 수정했다.

근거: `work/remaining-v46/before.json`, `scope-before.json`, `scope-dry.json`, `tests.xml`, `public.json`, `after.json`. 공개 인터넷 100동시 성능은 이번 변경에서 재측정하지 않았고 목표 통과로 보고하지 않는다.

## 남은 완료 기준

기준일 없는 원천의 거래량을 현재값으로 복구하려면 실제 해당 거래일 자료가 필요하다. 토스 목록 밖 종목의 거래 자료·전 종목 전체 과거·TTM/주식분할·배당 기업행사·실제 장중 수신·공개 성능·아버님 실사용은 남았다. 이번 null 처리는 미확보 데이터를 확보했다고 표시하는 우회가 아니다.
