# 가격·거래 자료 수집 상태 판정 수정

2026-10-10. 이 문서는 공개 반영 전 수정 기록입니다. 운영 API는 `20261010-history-contract-v116`이며, 저장 구조 전환 중에는 컨테이너를 교체하지 않습니다.

## 수정

최신 가격 조회가 빈 응답으로 실패해 마지막 정상 가격 이력을 유지한 경우, 기존 작업 상태가 과거 커서 완료와 행 수만 보고 `ready`로 바뀌었습니다. 가격 수집 결과의 `stale`, `partial`, `error`를 우선 유지하도록 수정했습니다. 같은 날 재방문에서도 오래된 완료 표시를 바로잡습니다.

정상적으로 과거 마지막 페이지에 도달한 빈 응답은 기존대로 완료 처리합니다. 마지막 정상 행, 원본, 과거 커서와 공급자 호출 주기는 변경하지 않았습니다. 최신 실패와 과거 범위 확보 여부는 서로 다른 상태입니다.

## 검증

- 수정주가·원주가의 실패를 기존 코드에서 재현한 뒤 회귀 검사에 추가했습니다.
- 관련 검사 97개와 Python 컴파일을 통과했습니다. SQLite fixture 검사이며 운영 데이터 수집 증거가 아닙니다.
- 변경 구역에 새 Ruff 위반은 없습니다. 관련 파일 전체에는 기존 위반 49개가 있어 전체 린트 통과로 표현하지 않습니다.
- 토스 공식 명세를 다시 읽어 1.2.24, 공개 GET 25개, 적용 대상 24개와 허용 목록의 일치를 확인했습니다. 인증 API를 새로 호출한 검사가 아닙니다.

## 공개 반영 조건

저장 전환의 연속 수집 중단 상태를 유지하기 위해 배포는 전환 이후에 진행합니다. 같은 소스의 API·worker를 반영하고 버전·대표 조회·수집 진행을 확인한 다음 이 항목을 갱신합니다. 전 종목 과거 자료, TTM·분할·배당의 전체 확보와 장중 실제 수신은 이 수정만으로 완료되지 않습니다.

## 거래 자료 확보 현황 연결

토스 투자자·공매도 거래·신용융자·대주·대차 원본이 정상적으로 정규화돼도 `collection` 상태가 갱신되지 않아 일부 항목이 계속 대기로 집계됐습니다. 각 자료의 실제 날짜와 숫자를 검사한 작은 검증 결과를 저장하고, 새 projection과 변경 없는 재사용 모두 확보 현황에 반영하도록 수정했습니다. 공매도 순보유잔고를 공매도 거래로 대체하지 않습니다.

정규화 저장이 원자적으로 수행되는 경로는 현황 갱신도 같은 트랜잭션에 포함합니다. 기존 저장 방식은 현황 저장 실패 뒤 같은 자료 버전을 재시도할 수 있습니다. 기존 정상 자료의 날짜와 원본은 빈 응답·연결 실패 때 보존하고 지연 상태로 표시합니다. `ready`는 확인한 자료의 사용 가능 상태이며, 전체 과거 기간 완료와 별도입니다.

관련 데이터·API·출처·작업자 검사 183개가 통과했습니다. 고정 입력과 SQLite 검증이며 전 종목 실제 수집 검증이 아닙니다. 확보 현황은 배포 후 해당 종목의 다음 정상 처리부터 정정되며, 아직 운영 수치가 복구됐다고 보고하지 않습니다.

## 최신 자료 갱신과 과거 완료 자료의 현황 보정

과거 페이지를 최근에 받았다는 이유로 오래된 최신 일봉·투자자 자료의 갱신을 미루던 경로를 수정했습니다. 최신 페이지의 수신 시각을 별도로 사용하며, 명시적으로 없거나 잘못된 시각은 최신으로 간주하지 않습니다. 시각이 분리되지 않은 기존 저장값에만 종전 수신 시각을 적용합니다. 수신 시각은 재시도 판단에 쓰며 실제 거래일이나 자료 상태를 바꾸지 않습니다.

과거 수집이 끝나 최신 공급자 호출을 생략하는 경우에도 기존 검증 결과를 확보 현황에 반영합니다. 유효한 작은 검증 기록은 재사용하므로 원천 재호출이나 전체 과거 자료 재조회가 필요하지 않습니다. 커서와 마지막 정상 자료를 보존합니다.

수정 전 실패 9개를 확인한 뒤 수정 후 통과했습니다. 관련 262개 검사가 통과했으며 기존 183개 검사를 모두 포함합니다. 고정 입력·SQLite 검사로, 공개 서버 적용과 실제 최신 자료 수신은 별도 확인 대상입니다.

## 종목·차트 주소와 뒤로 가기

종목을 열 때 이전 주소를 이력에 추가하던 처리를 실제 선택한 종목 주소로 수정했습니다. 공유 링크·새로고침·뒤로 가기·앞으로 가기에서 종목, 분석 화면, 선·캔들 선택이 유지됩니다. 종목을 바꾸면 종목별 세부 선택을 분리하고, 미리보기와 전체 상세의 동작을 구분합니다. Next.js 내부 이력 필드를 복사하거나 삭제하지 않습니다.

PC·모바일의 고정 입력 검사와 실제 공개 자료 GET을 사용하는 로컬 화면 검사 8개가 통과했습니다. 같은 수정의 정적 빌드에서 주소·이력 4개와 요청 효율 5개, 총 9개 검사가 통과했습니다. 지수 최초 요청 1회, 닫힌·숨겨진 화면의 갱신 중지와 복귀를 확인했습니다. 브라우저별 새 저장 공간과 고정 입력을 사용한 검사입니다. 이 단계에서는 공개 서버의 앱을 교체하지 않았습니다.
