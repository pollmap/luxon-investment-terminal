# v24 — 기간별 조회, 토스 옵션, 재무·배당 검증

이번 변경은 13.8MB 전체 가격의 자동 조회를 없애고 남은 시장 조회 옵션을 연결한다. 저장된 과거 자료와 기존 전체 조회 API는 보존한다. TTM·배당의 불완전한 근거를 완료로 바꾸지 않는다.

## 완료 판정

각 기능에 구현 / 실제 자료 / 화면 확인 / 공개 반영을 따로 기록한다.

| 대상 | 통과 조건 | 이번 변경 |
|---|---|---|
| 첫 종목 화면 | 전 기간 `/prices` 자동 요청 0건, 가격 전송 gzip 100KB 이하 | 기간별 SQL 조회, 수익률 5개 기준일만 전달 |
| 장기 차트 | 일·주·월봉, 20봉 평균이 전체 원본 계산과 일치 | 첫 표시 봉의 전체 기간, 거래정지 전 계산 자료까지 확보 |
| 토스 과거 환율 | 통화·시간대·과거 시점 원문과 일치, 현재 캐시 보존 | UTC 정규화, 두 환율 방향, 한국 시각 입력 |
| 거래 일정 | 선택 날짜의 한국·미국 실제 세션과 일치 | 날짜별 캐시, 한국 시각 표 |
| 상장 목록 | 시장·상장 상태·주식 종류의 실제 필터 확인 | 상장/예정/폐지, 보통/우선, 검색·더 보기. 미등록 종목은 잘못된 상세 링크를 만들지 않음 |
| 기관 세부 수급 | 매수·매도·순매수와 억원 단위 확인 | 금융투자·보험·투신·사모·은행·기타금융·연기금 |
| TTM | 같은 회사·회계 기준·실제 기간·공개 시점, 이익/가중평균 주식 수 대조, 분할 기준 근거 | 회사 누락·공개일·차원 충돌 거부, 최신 기간별 준비 상태. 주식분할 기준 미확보 상태는 유지 |
| 배당 재투자 | 주식 종류, 권리·배당락·실제 지급, 기간 전체 기업행사, 원주가 확인 | 공시의 주식 종류 분리, 예정/실제 지급 분리, 저장 원문 해시 검증 후 재처리. 자료 범위가 불충분하면 계산 차단 |
| REST 완료 | 요청 옵션→원본→정규화→저장→공개 응답→표/차트가 일치 | 아래 20개 계약별로 실응답과 옵션을 별도 확인 |
| 실시간 완료 | 거래일 새 체결/호가, 화면 반영, 단절 복구 증거 | 휴장 중 구독 승인으로 통과 처리하지 않음 |
| 전 종목 완료 | 종목×자료×기간의 마지막 페이지·무결성·오류 처리 | 404는 미해결 응답으로 분류, 원천 미제공으로 간주하지 않음 |

## REST 적용 범위

기준은 Toss OpenAPI 1.2.19의 공개 시장 조회 20개 GET이다. 인증은 수집 작업자 한 곳이 소유한다. 주문·개인 계좌·미국 개별 종목은 제외한다.

| 계약 | 제품 기능 | 확인할 옵션 |
|---|---|---|
| `/prices` | 현재가·목록 | 최대 200개 묶음, 부분 오류·거래일 |
| `/orderbook` | 호가 | 종목·시장·잔량·시각 |
| `/trades` | 최근 체결 | 종목·최신 순서, 추정 매수/매도 금지 |
| `/price-limits` | 상·하한가 | 종목·거래일 |
| `/candles` | 선·캔들·OHLC·거래량 | 1분/일, before, 수정/원주가, 전체 커서 |
| `/stocks` | 종목 기본정보 | 코드 묶음·발행주식 수·시장 |
| `/stocks/all` | 상장 목록 | 시장·상태·securityType·commonShare |
| `/stocks/{symbol}/warnings` | 거래정지·VI·주의사항 | 시장별 항목·빈 결과 |
| `/stocks/{symbol}/investor-trading` | 투자자 수급 | 집계 기간·전체 커서·기관 구분 |
| `/stocks/{symbol}/program-trades` | 프로그램 | 기간·차익/비차익·매수/매도 |
| `/stocks/{symbol}/short-selling` | 공매도 거래 | 기간·단위·전체 커서. 순보유잔고와 별개 |
| `/stocks/{symbol}/credit-trades` | 신용 | 기간·잔고/발생·전체 커서 |
| `/stocks/{symbol}/securities-lending` | 대차 | 기간·잔고/발생·전체 커서 |
| `/exchange-rate` | 환율 | USD/KRW·KRW/USD·과거 dateTime |
| `/market-calendar/KR` | 국내 장 일정 | date·KRX/NXT/통합·휴장 |
| `/market-calendar/US` | 미국 장 일정 | date·서머타임·한국 시각 |
| `/rankings` | 기간별 순위 | 6종·기간·유의종목 제외, 불가 조합 차단 |
| `/market-indicators/prices` | 지수·금리 | KOSPI/KOSDAQ·국채 6종, 금리 % |
| `/market-indicators/{symbol}/candles` | 지수·금리 차트 | 지원 간격·전체 커서 |
| `/market-indicators/{symbol}/investor-trading` | 시장 수급 | 일/주/월/연·기관 세부·전체 커서 |

GET 20개를 한 번 호출했다는 증거는 모든 옵션·기간·종목의 완료 증거가 아니다. HTTP 200이어도 빈 응답·오래된 자료·잘못된 단위가 아닌지 대조한다. 레퍼런스 사이트의 화면 개수를 기능 완료 지표로 쓰지 않는다.

## 계산·운영 판단

- 과거 TTM 하나가 계산되어도 최신 분기의 TTM을 준비 완료로 표시하지 않는다.
- 기본 EPS의 분자는 보통주 귀속이익, 분모는 기간 가중평균 주식 수다. 분기 EPS 단순 합산과 근거 없는 주당 기준 상수는 금지한다.
- 공시의 종류주식 배당을 종목코드 끝자리만으로 여러 우선주에 복사하지 않는다.
- 배당 지급 예정일이 지났다는 이유만으로 지급 완료를 만들어내지 않는다. 실제 지급 확인 없이 재투자 거래를 생성하지 않는다.
- 배당 파서 버전 변경 시 이미 저장한 ZIP을 SHA-256 대조 후 재처리한다. 이전 해석이 무효가 되면 검토 보관소로 옮기며 원본은 남긴다.
- 공개 배포 전 DB 백업을 별도 DB에 복원한다. 기존 서비스·공유 DB 볼륨을 변경하지 않고 앱 버전으로 되돌릴 수 있게 한다.
- 기존 검색 색인은 이미 구현되어 있으므로 다시 만들지 않는다. 이전 감사 계획의 검색 색인 항목은 신규 개발이 아니라 검증·최적화 대상으로 정정한다.

검증 결과와 공개 반영 상태는 같은 폴더의 `RESULTS.md`와 JSON 증거로 기록한다. 목표 성능과 실제 측정을 구분한다.

공식 근거: [토스 REST](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json), [IAS 33](https://www.ifrs.org/issued-standards/list-of-standards/ias-33-earnings-per-share.html/).
