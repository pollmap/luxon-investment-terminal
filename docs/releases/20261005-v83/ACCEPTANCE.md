# v83 — 대표 기업 주당 기준 검토와 실적 비교선 연결

## 변경 내용

SK하이닉스(000660)와 현대차(005380)의 기존 주당 기준은 2026-06-30에 끝나 있었다. 최신 TTM 실적은 제공되는데 이후 저장 가격과 같은 단위인지 확인하지 못해 2026-10-02 가격 비교선이 끊겼다.

v83은 share-basis 검토에서 액면 단위 변경과 발행주식 수 변동을 구분한다. 분할·병합·무상증자·주식배당·감자 등 단위 변경은 계속 자동 연장을 막는다. 유상발행·DR·자기주식 소각 등 발행주식 수 변동은 회사·접수번호가 일치하는 문서 URL과 해시, 판정 근거가 갖춰져야 검토 기록으로 포함한다. 그런 문서가 빠지거나 다른 회사 자료면 연장을 거부한다.

## 실제 원문 확인

- SK하이닉스: 2026-07-01~2026-10-02 DART 주요사항 공시 24건을 한 페이지에서 확인했다. DR 발행 정정 2건, 보통주 17,790,000주 발행 결과 1건, 자기주식 소각 결정 1건을 문서 원문·해시와 함께 검토했다.
- 현대차: 같은 기간 24건을 확인했다. 2026-08-31 예정된 기보유 자기주식 소각(보통주 1,291,274주, 우선주 1,214,332주) 문서를 확인했다. 공시는 자본금 감소 없이 주식 수를 줄이는 내용이었다.
- 두 종목 모두 기준 구간의 마지막 저장 원주가는 2026-10-02다. 삼성전자도 v82에서 같은 가격 기준일까지 검증되어 있다.

공시 목록 페이지 해시·행과 원문 발췌·문서 SHA-256은 `DART 조회 구간` (로컬 보존 자료: `../../share-basis-window-v82-representatives.json`), `주식 수 변동 문서` (로컬 보존 자료: `../../share-basis-blocker-documents-v82.json`)에 보존했다. 적용 전 기준과 연장 미리보기는 `이전 기준` (로컬 보존 자료: `../../share-basis-prior-v82.json`), `검증된 extension` (로컬 보존 자료: `../../share-basis-extension-v83-preview.json`)에 있다. 운영 DB의 적용 결과는 `실제 적용 기록` (로컬 보존 자료: `../../share-basis-live-extension-v83.json`)이다.

## 적용·검증

- 운영 DB의 기존 기준은 종목별 `share-basis-review-history`에 먼저 보관한 다음 종료일을 2026-10-02로 연장했다. 가격·재무 원본 사실은 변경하지 않았다.
- 공개 API·worker release는 `20261005-share-unit-event-review-v83`이다. 배포가 웹·OpenAlgo·PostgreSQL·Redis 컨테이너를 재시작하지 않았음을 확인했다. 적용 과정에서 DB evidence/raw archive는 기록됐으며 캐시 무효화 알림도 전달됐다.
- 공개 `/health`는 v83, 대상 2,766종목을 반환했다.
- EPS·OCF·EBITDA×삼성전자·SK하이닉스·현대차의 공개 분석 요청 9건이 모두 HTTP 200이었다. 각 차트에는 261개 주간 가격 시점이 있었다. 2026-10-02 마지막 가격에서 8배 시험 입력 기준 8개 비교선이 가능했고, 현대차 OCF는 -10,379.67원/주로 가격만 제공했다. 이 입력 배수는 분석 경로 확인용이다.
- 대표 3종목의 시세 및 기업분석 페이지 6개가 모두 HTTP 200이었다.
- share-basis·단위변환·분석 시계열 회귀 **51개 통과**, Ruff `F`/`I001` 통과.

세 종목의 실적기간은 최신 확인된 2026-06-30이고 가격일은 2026-10-02다. 서로 다른 기준일을 현재 실적처럼 합쳐 표시하지 않는다.

## 남은 검증

이는 대표 3개 종목의 범위 검증이다. 전체 KOSPI·KOSDAQ 종목의 주당 기준·TTM 입력, 전체 과거 자료와 404, 현금배당 이력, 실제 장중 체결·호가 수신 및 복구, 공개 WAN 성능, 아버님의 실사용은 완료되지 않았다. 현대차 OCF의 음수 상태는 의도된 무비교선 처리다.
