# v102 — 첫 차트 병렬 조회와 TTM 재수집 회귀 수정

관측일: 2026-10-10 KST. 대상 버전: `20261010-chart-projection-v102`.

이 기록은 이번 수정의 구현·실제 자료·화면·배포를 구분합니다. 전 종목 자료와 공개 성능 목표의 전체 완료 보고가 아닙니다.

## 1. 첫 차트 요청

종목 요약 뒤에 시작하던 차트 조회를 요약과 함께 시작하도록 변경했습니다. 선·5분 캔들·장기 차트를 대상으로 링크와 저장된 선택값을 먼저 복원합니다. 초기 응답은 상세 화면 안에서만 공유하며 이후 폴링은 기존 조회 경로를 사용합니다.

- 5분봉 30초, 선·장기 차트 60초가 지나면 초기 응답을 다시 사용하지 않습니다. 경과 시간은 요청 시작부터 계산합니다.
- 기간·종목 변경과 화면 닫기에서 요청을 취소합니다. 숨긴 화면에서는 신규 갱신을 줄이고 복귀 시 만료를 검사합니다.
- 실제 거래일·자료 시각·서버 캐시 정책은 바꾸지 않습니다.
- 요약 실패 시 차트 **요청**은 독립적으로 진행하지만, 기존 요약 오류 화면에서 차트 **표시**까지 복구하는 변경은 아닙니다.

로컬 Chromium 지연 fixture(요약 600ms·차트 250ms)에서 첫 선 차트 요청 시작은 요약 시작 후 1,019ms → 12ms, 응답 준비는 1,270ms → 272ms였습니다. 요약 응답은 615ms/609ms였습니다. 이는 직렬 의존성 제거의 시험이며 공개 API p95·LCP·전체 서비스 개선 배수가 아닙니다.

새 브라우저 시험 9개, 로더 단위 시험 8개, TypeScript 검사가 통과했습니다. 이후 공개용 정적 산출물에서 새 시험 9개와 기존 요청 효율 시험 4개를 함께 실행해 **13개 모두 통과**했습니다. 개발 모드에서 2회 요청으로 실패했던 지수 조회도 정적 앱에서는 최초 1회 공유·닫기·숨긴 화면 중단·복귀 재조회 검사를 통과했습니다. 상세 원본: `work/first-chart-v102/README.md`, `timings.json`, `static-report.json`.

## 2. 실제 재수집 뒤에도 TTM 기준 유지

worker의 `official` 저장 경로가 독립된 주식 기준을 분석 캐시에 결합하지 않던 문제를 수정했습니다. 저장과 조회가 같은 결합 함수를 사용하며 원본 revision과 주식 기준 revision을 함께 기록합니다. 최신 revision과 맞지 않는 캐시를 거부하던 기존 조회 보호도 유지합니다.

- 관련 회귀 31개 통과. 실제 기아 105개 사실과 승인된 원장은 수정 없이 대조했습니다.
- v102 배포 뒤 00:59:27 KST의 자연 재수집에서 공식 자료와 분석 캐시가 같은 revision으로 저장됐습니다.
- 01:04:51 KST에 공개 API를 읽기 **전** DB를 확인했습니다. 검증된 정정 자료 3개는 `ready`, 원본 3개는 `share_basis_required`이며 주식 기준 revision도 일치했습니다. API 호출에 의한 사후 복구로 이 결과를 만든 것이 아닙니다.
- 실제 TTM 기본 EPS: 2025년 말 19,381.673921원, 2026년 3월 말 17,999.712633원, 6월 말 18,177.723746원.
- 승인 기준은 2025-01-01~2026-06-30 그대로입니다. 현재 가격 비교는 `reported_only / requires_price_alignment`를 유지합니다. 6월 이후 분할 근거를 확보한 것으로 처리하지 않습니다.

증거: `work/operations-20261009-v94/v102-projection-after-worker.json`, `work/ttm-bootstrap/KIA_PROJECTION_REFRESH_FIX.md`.

## 4. 성능·자료·외부 백업의 한계

[v101 검증](../20261010-v101/ACCEPTANCE.md)의 공개 HTTP/2 동시 스트림 100개 시험에서 검색 300ms·상세 500ms 목표는 미달입니다. 이번 프런트엔드 병렬화가 그 API 지연을 해결했다고 보고하지 않습니다. 큰 백업 전송 중에는 같은 공개 부하 시험을 반복하지 않습니다.

토스 과거 수집과 다른 기업·기간의 TTM·분할·배당 근거, 실제 거래일 체결·호가 수신·복구, 실제 Android와 아버님 사용 평가가 남아 있습니다. DART 점검 응답과 토스 목록 누락을 임의의 무자료나 전 종목 완료로 처리하지 않습니다.

PC 외부 백업은 등록된 `KoreaStocks-OffsiteBackup` 작업으로 첫 전송 중입니다. 새 서버 완결본은 2,372,779,444바이트이며 일별 예약은 05:30 KST입니다. 01:11:20 KST 읽기 공유 핸들로 실제 길이 1,054,707,712바이트와 SSH I/O 증가를 확인했습니다. 열린 파일의 디렉터리 크기·수정 시각 갱신이 늦어 정체처럼 보였지만 전송은 계속되고 있었습니다. 전송·해시·암호화 검증과 PostgreSQL 복원, 미래 예약 실행은 별도 완료 조건입니다. 기존 검증된 외부 복구본을 자동 교체하지 않습니다. 증거: `pc-offsite-progress-check.json`.

자동 승인 검토가 차단한 실패한 로컬 복원 시험 폴더는 보존했습니다. 이번 차수에서 원본 자료·기존 복구점 추가 삭제는 하지 않았습니다.
