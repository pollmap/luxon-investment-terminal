## 이번 변경

1. 같은 이벤트 루프 회차에 들어온 자료 버전 조회를 묶어 DB 요청을 줄였습니다. 대기를 추가하거나 시세 캐시 유효기간을 늘리지 않았습니다.
2. Cloudflare 화면의 공개 데이터 요청은 기존 VPS API로 직접 연결합니다. 정적 파일은 Cloudflare가 제공하고 API의 추가 WAN 경유와 Worker 동적 요청을 줄입니다. 기존 Worker API 경로는 호환용으로 남깁니다.
3. 정확한 Cloudflare Origin만 허용하는 CORS와 WebSocket 경계를 추가했습니다. CSV POST·취소·ETag·조회 오류를 보존합니다. Origin 없는 응답도 `Vary: Origin`을 반환해 캐시를 먼저 채운 순서 때문에 조회가 차단되는 문제를 방지합니다.
4. 새로 수집하거나 정정된 시계열의 동일 출처를 해시로 공유 저장합니다. 기존 자료는 일괄 변환하거나 삭제하지 않았습니다. 누락·변조된 출처는 읽기 오류로 차단합니다.
5. 배당 수집에서 만료된 DART 오류 응답을 계속 재사용하던 문제를 수정했습니다. 오류 원본은 보존하고 재시도 시 실제 원문을 다시 조회합니다.
6. 최초 주식 기준 검토가 없는 기업도 누락 입력 작업을 생성하도록 연결했습니다. 기아의 검토된 공시 EPS·가중주식·이익 입력을 연결하는 어댑터가 포함됩니다. 주식 기준 검증을 자동 승인하지 않습니다.

## 공개 기능 검증

실제 공개 HTTP 요청으로 상세 200·종목 일치, CSV 200·종목 포함, preflight 204, 다른 Origin 비노출을 확인했습니다. Origin 없음→Cloudflare와 반대 순서의 캐시 prime 모두 통과했습니다. Cloudflare Origin의 WebSocket 연결 후 `snapshot`을 수신했습니다. 이는 **새 증권사 장중 체결을 수신한 증거가 아닙니다.**
