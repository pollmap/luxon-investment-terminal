# 종목별 DART 재무 데이터

종목 상세 응답에 전체 재무제표와 지표 이력을 한꺼번에 실으면 응답이 커지고 첫 화면이 느려집니다. 재무 자료는 종목 상세와 분리해 요청한 보고서만 불러옵니다.

## 공개 API

- `GET /api/market/v1/securities/{종목코드}/financials`는 준비된 보고서 목록을 반환합니다.
- `GET /api/market/v1/securities/{종목코드}/financials?year=2026&report_code=11012&basis=CFS`는 연결 또는 별도 재무제표 한 건을 반환합니다. 보고서 코드는 `11013` 1분기, `11012` 반기, `11014` 3분기, `11011` 연간입니다.
- `GET /api/market/v1/securities/{종목코드}/financials?year=2026&report_code=11012&category=M210000`는 재무비율 한 분류를 반환합니다. 분류는 수익성 `M210000`, 안정성 `M220000`, 성장성 `M230000`, 활동성 `M240000`입니다.

자료가 아직 없으면 빈 행과 `pending` 또는 `no_data` 상태를 반환합니다. 별도 단위가 확인되지 않는 재무비율 원문 값은 임의로 퍼센트나 배수로 바꾸지 않습니다.

## 종목 화면

종목 상세의 `재무·지표` 탭에서 재무제표와 주요 재무지표를 나눠 봅니다. 재무제표는 연결·별도 기준, 보고 기간, 표 종류를 선택하고 계정 이름을 검색할 수 있습니다. 중간보고서 손익·포괄손익은 DART 필드 정의에 따라 3개월과 누적 값을 전환하며, KRW 계정은 억원 단위로 읽기 쉽게 표시합니다. 표는 내부 스크롤을 사용해 상세 페이지의 다른 정보와 분리합니다.

주요 재무지표는 수익성·안정성·성장성·활동성 분류로 전환합니다. API가 반환한 값 자체는 곱하거나 나누지 않습니다. 지표 이름에 따라 퍼센트 또는 배수 단위를 표시하고, 구분 규칙이 없는 항목은 수치만 보여줍니다. 지표는 처음에는 최근 확보한 보고서만 제공하며, 다른 기간은 종목을 열어 둔 동안 순차 수집합니다.

## 자동 수집 범위

기업 개황·주요 재무계정·사업보고서 항목은 기존 전 종목 순환 작업이 계속 채웁니다. 전체 재무제표와 DART 재무비율처럼 용량이 큰 자료는 사용자가 종목 상세를 열었을 때 우선 수집합니다. 보고서별 체크포인트로 종목마다 최대 3개 API 요청을 한 번에 처리하고, 실패·재시작 뒤에도 이어서 진행합니다. 최근 3개 사업연도의 1분기·반기·3분기·연간 보고서에서 연결·별도 재무제표를 확보합니다. DART 재무비율 API가 제공하는 2023년 3분기 이후 자료는 네 지표 분류로 수집합니다. 아직 공개되지 않은 보고기간은 일정상 뒤로 미뤄 재요청하지 않습니다.

성공 자료는 180일 뒤 다시 확인하고, 자료 없음은 30일 뒤 재확인합니다. 일시 오류는 체크포인트에 남기고 작업을 이어갈 때 다시 시도합니다. 호출 안전 예산에 도달하면 다음 기준일에 재개합니다. 수집 원문은 내용 해시로 보존하며, 정정된 값은 기존 보고서 스냅샷을 덮지 않고 새 스냅샷을 가리키도록 합니다.

종목 상세 화면은 목록 인덱스만 받고, 사용자가 보고서를 열 때 해당 보고서만 별도 API로 불러옵니다. 사용자 화면에는 제공처, 내부 수집 시각, API 한도를 표시하지 않습니다. 기준 기간과 연결·별도 구분은 숫자의 의미를 구분하는 데 필요한 재무 화면에서만 사용합니다.

## 공식 API 명세

- [단일회사 전체 재무제표](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020): 2015년 이후, 네 보고서 코드, 연결(`CFS`)·별도(`OFS`) 선택.
- [단일회사 주요 재무지표](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2022001): 2023년 3분기 이후, 수익성·안정성·성장성·활동성 분류.

실제 보유량은 상장 폐지·신규 상장, 공시 자료 제출 여부, DART 응답과 백그라운드 작업 진행에 따라 달라집니다. 계획에 포함된 범위를 모든 종목이 이미 보유한 것으로 간주하지 않습니다.
