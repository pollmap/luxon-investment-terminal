### 공개 서비스용 데이터와 증권사 API 구분

일반 사용자 화면에는 출처 이름, 수집 시각, 원천 한도를 표시하지 않습니다. 운영자는 데이터 검증과 오류 해결을 위해 이 정보를 내부에 보존합니다. 회사 실적의 회계연도·분기와 차트의 날짜처럼 숫자의 의미에 꼭 필요한 기간은 데이터와 함께 다룹니다.

KRX Open API 목록은 지수·주식의 일별자료를 2010년 이후 범위로 안내합니다. KRX의 실시간 데이터 분배 상품은 별도 항목으로 제공되며 체결가·호가·회원사 매수/매도 등 필드를 포함합니다. 현재 public 서비스의 무료 Open API 연결을 실시간 거래소 피드로 표현하지 않습니다. 실제 전 종목 틱을 공개 웹에 제공하려면 배포 목적에 맞는 KRX 계약·이용 승인을 별도로 확인해야 합니다.

한국투자증권 Open API 공식 안내는 개인 고객의 시세정보 이용을 본인 자산의 투자 목적으로 한정하고 제3자 제공을 허용하지 않는다고 명시합니다. 따라서 개인용 KIS 키로 받은 시세를 이 공개 웹의 방문자에게 중계하지 않습니다. 제휴 제공 승인이 확인되면 그 전용 경로를 별도 검토합니다. 키움 API도 계좌 보유와 서비스 신청이 필요하며, 현재 운영 서버에서는 키와 허용 IP 등록이 완료되지 않아 직접 피드가 켜져 있지 않습니다. 키움 시세도 공개 재배포 가능 범위를 승인된 서비스 조건에서 먼저 확인합니다.

OpenDART는 단일회사 전체 재무제표와 다중회사 주요계정/주요 재무지표 API를 구분해 제공합니다. 현 수집기는 종목 상세를 순회해 공시·기업정보·전체 재무제표를 저장하고 있습니다. 회사 묶음 호출은 요약재무 커버리지를 넓히는 데 적용할 수 있고, 전체 계정과 공시 원문은 회사별 자료 구조를 유지해야 합니다.
