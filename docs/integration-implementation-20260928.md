### 재무·원본·계산

- ZIP·PDF·XBRL을 바이트 그대로 보관하고 별도 해시·메타데이터를 둡니다.

- `exact_value`/Decimal을 계산·저장에 사용하고 기존 숫자형 표시 계약을 유지합니다.
- TTM은 연속 네 분기 손익·현금흐름만 합산합니다. 누적 금액이 없으면 단독 금액으로 대신하지 않습니다. EPS·잔액·비율은 합산하지 않습니다.

인증정보만 있으면 모든 기능이 즉시 완성되는 상태는 아닙니다. 위의 정규화·보완 어댑터·실기기 검증도 남아 있습니다.

## 재현과 핵심 코드

이미 실행 중이면 상단 주소를 사용합니다. 해당 포트 앱을 종료한 뒤 다시 시작할 때:

```powershell
.\scripts\start-market.ps1 -SkipWorker -WebPort 3232 -ApiPort 8230 -BuildDir .next-integration-v20
.venv\Scripts\python.exe scripts/verify_market_runtime.py --origin http://127.0.0.1:3232 --output docs/runtime-current.json
.venv\Scripts\python.exe -m scripts.audit_market_coverage --output docs/coverage-current.json
```

새로 빌드할 때는 `apps/web`에서 `NEXT_BUILD_DIR=.next-integration-v20`, `MARKET_API_BASE_URL=http://127.0.0.1:8230`을 설정한 뒤 `pnpm run build`를 실행합니다. 빌드와 실행의 API 포트가 같아야 합니다.

`-SkipWorker`는 기존 수집기 중복 실행을 피하기 위한 옵션입니다. 운영의 새 수집 코드 활성화를 뜻하지 않습니다. 원본 재처리 도구는 기본 읽기 전용이며 `--apply`일 때 백업 후 저장합니다.

주요 코드: `valuation_series.py`, `bars.py`, `performance.py`, `krx_openapi.py`, `kis_supplements.py`, `xbrl_facts.py`, `fact_store.py`, `kiwoom_rest.py`, `kiwoom_stream.py`, `event_archive.py`, `app.py`, `components/market/valuation-chart.tsx`, `detail.tsx`, `depth-panel.tsx`, `activity-panel.tsx`, `app/stocks/market.css`.

원문: [FAST Graphs 공개 화면](https://www.fastgraphs.com/platform/research-terminal), [키움 공식 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API), [DART XBRL 명세](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019019). 유료 화면 전체를 확인한 것으로 보고하지 않습니다.
