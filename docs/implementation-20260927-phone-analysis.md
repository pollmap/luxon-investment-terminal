# 국내증시 모바일·분석 구현 결과

검증일: 2026-09-27. 최신 로컬 화면: http://127.0.0.1:3221/stocks. Web `.next-phone-v10`, API 8221. 외부 공급자 worker를 추가 실행하지 않은 저장 스냅샷 기반 미리보기입니다. 공개 서버의 새 배포가 아닙니다.

## 이번 변경

- 휴대폰 검색을 상단 전체 너비로 표시하고, 헤더가 본문을 가리던 고정 높이를 제거했습니다.
- 보통·크게·더 크게 설정을 상단에서 열고 기기에 저장합니다. 예전 큰 글씨 설정도 읽습니다.
- 기본 순위 10개, 거래대금·시가총액 버튼, 큰 순위 선택창을 제공합니다. 비교 체크박스는 선택 모드에서만 나타납니다.
- 현재가를 눌러도 종목이 열립니다. 관심 저장의 연속 터치로 같은 종목이 바로 해제되는 것을 방지합니다.
- 기업정보는 소개에서 실적·재무·가치평가와 공시로 들어가는 큰 행으로 정리했습니다.
- 설정에서 글자 크기 창으로 이동할 때 이전 창의 history.back이 새 창을 닫던 오류를 수정했습니다.
- EPS/BPS, 연결/별도, 기간·배수를 바꾸는 주가·실적 비교와 별도의 사용자 가정 계산기를 연결했습니다. 현재 저장된 삼성전자 실제 자료에서 연간 3개 기간의 가격·실적 비교가 응답하는 것을 확인했습니다.
- 분석 화면의 요청 취소·이전 결과 제거·늦게 도착한 계산 응답 무시를 적용했습니다. 재무 화면에서는 분석 구역을 열 때 조회합니다.
- TTM 계산에 실제 기간 시작·종료, 연속 네 분기, 연결 기준·통화·단위를 요구합니다. 누적→단독 분기와 연간→4분기 환산, 정정 버전, 비12월 결산을 검사합니다.
- OpenDART 주요계정의 thstrm_dt를 읽는 수집기와 100개 회사 단위 재개 지점을 추가했습니다. 현재 수집기는 손익 주요계정 대상이며 현금흐름 전체 TTM까지 완료한 것은 아닙니다.
- 대차·신용의 인증정보 누락을 원천 미제공과 구분합니다. 예전 unavailable 스냅샷도 화면에서 연결 준비로 표시합니다.

## 검증과 성능

- 백엔드 회귀 68개 통과. 이후 인증 상태 수정 관련 42개 통과(일부 중복이므로 110개로 합산하지 않음).
- 프로덕션 빌드 및 TypeScript 통과. 변경한 React 파일 ESLint 통과.
- 최종 v10 전체 브라우저 검사 38개 통과(실패·건너뜀·재시도 통과 0). `market-browser-results.json`의 stats에 기록했습니다. 중간 v9 실행에서 검색 대기 한 건이 시간 초과됐으나 개별 재검사와 이후 전체 실행에서 통과했습니다.
- 360·390·430px, 768·1440px, 라이트·다크·큰 글씨, 정적 종목 헤더, 저장·뒤로 가기를 검사했습니다. 실제 Galaxy Chrome/Samsung Internet 및 아버님 평가는 아닙니다.
- 동시 요청 측정 (로컬 보존 자료: `mobile-analysis-load-20260927.json`): 로컬 API 100개 동시 연결, 경로별 300회, warm cache, gzip 전체 응답 읽기. 검색 p95 294.76ms, 요약 406.87ms, 전체 상세 370.45ms, 오류 0. 같은 PC에서 브라우저 검사도 진행 중이었습니다. 공개 서버·실제 100명 사용·모바일 렌더링 성능으로 일반화하지 않습니다. 10배 개선은 검증하지 않았습니다.

## 외부 연결과 남은 완료 조건

한투·키움은 새 키 발급 예정입니다. OpenDART 키는 존재하지만 이번 실제 요청은 ConnectError였습니다. SSH는 인증 이전에 포트 22 접근이 거부되어 공개 배포를 변경하지 않았습니다.

[증권사 설치 준비](broker-tools-setup.md): 공식 키움 MCP·CLI, 한투 코드 검색 MCP 설치·검증 스크립트를 만들었습니다. GitHub 접속과 uv 실행 제한으로 설치·MCP tools/list·CLI doctor는 통과하지 못했습니다. 파일 생성과 구문 검사를 설치 완료로 처리하지 않습니다.

전체 완료까지는 공급자 인증과 장중 수신·복구, 실제 기간 자료와 전 종목 보완, 남은 분석·일정 기능, 공개 서버 새 버전, 실제 Android와 아버님 사용 과제가 남아 있습니다.

공식 데이터 명세: [OpenDART 주요계정](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS002&apiId=2019017). thstrm_dt가 단일 날짜이거나 기간이 불분명하면 TTM 대상에서 제외합니다.
