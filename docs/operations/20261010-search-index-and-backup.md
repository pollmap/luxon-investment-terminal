# 검색 색인 전달과 백업 대조 수정

2026-10-10 KST. 기존 공개 주소·브라우저 저장값·API 계약을 보존합니다.

## 검색

Cloudflare 화면의 종목 식별 색인만 같은 Origin의 기존 캐시를 사용합니다. 시세·상세·CSV·WebSocket의 VPS 직접 경로는 유지합니다. 색인 오류·잘못된 JSON·304·timeout에는 VPS를 한 번 조회하고, 사용자 취소와 전체 8초 제한은 유지합니다. Date/Age로 기존 응답의 남은 유효 기간만 적용합니다.

전송 경로 회귀 18개, 웹 전체 타입 검사, 변경 파일 ESLint가 통과했습니다. 실제 사전 조회는 같은 2,765종목·547,230바이트의 동일한 응답을 확인했습니다. VPS 최초/반복 3,302.48/629.69ms, Cloudflare MISS/HIT 1,473.72/271.93ms였으며 HTTP/1.1의 4회 관측입니다. 100동시 p95나 일반적인 속도 향상으로 확대하지 않습니다. 공개 반영과 브라우저 사용 결과는 배포 후 별도 기록합니다.

## 원본 대조 실패와 보존

운영 시계열·출처 두 테이블의 동일 snapshot 백업을 시도했습니다. 첫 시도의 1,324,895,868바이트 덤프는 수신했지만 이후 원본 대조가 실패했습니다. 완전한 복원 증거로 사용하지 않았으며 원본 테이블을 바꾸지 않았습니다. 두 번째 시도에서는 원본 대조를 전송보다 먼저 실행해 불필요한 재전송을 막았습니다.

두 번째 오류는 `QueryCanceled`, SQLSTATE `57014`로 확인했습니다. 시작 후 약 63초에 중단됐으며 수집기는 같은 컨테이너로 복구됐습니다. 장애 진단에는 고정된 계약 오류와 SQLSTATE만 기록하며 인증정보·원문 SQL 값은 출력하지 않습니다. 12개 순수 회귀 검사를 통과했습니다.

종류 목록 조회의 실행 계획은 1,701만여 행을 훑는 전체 스캔을 선택했습니다. 인덱스로 종류 키를 열거하는 개선을 진행하며 전행·원본 출처 해시 검증을 제거하지 않습니다. 실제 전체 복원·테이블 전환·서버 공간 회수는 아직 완료하지 않았습니다.

## PC 공간
