# 공개 국내 주식 대시보드 디자인 계약

2026-09-24. 적용 경로 `/stocks`. 현재 사용자가 승인한 공개 대시보드 계획이 과거 개인용 터미널의 범위와 색상 기본값에 우선한다. 기존 `/terminal`과 개인 데이터는 변경하지 않는다.

## 핵심 흐름
시장 → 조건 검색 → 종목 상세/빠른 확인 → 지표 설명 → 2~4종목 비교/관심 등록 → 목록 복귀. 검색·필터·열·정렬·스크롤을 보존한다. 종목명, 별표, 비교 체크박스는 서로 독립된 조작 대상이다.

## 정보와 디자인
시장 홈: 지수/시장 상태 → 거래대금 순위 + 관심/최근 종목 → 업종/공시. 종목 상세: 요약, 차트, 수급·거래원, 재무·지표, 기업·주주, 공시·자료. 모바일 하단 메뉴는 시장/종목 찾기/관심/비교다.

간격 4/8/12/16/24/32. 본문16, 보조14, 큰 글씨18. 표48px, 터치44px 이상. 숫자는 고정폭 오른쪽 정렬. 1200px 아래 보조열을 접고, 768px 아래 모바일 구조를 사용한다. 선택 청록과 상승 빨강/하락 파랑을 구분한다. 라이트/다크/시스템, reduced-motion을 지원한다.

## 데이터 상태
초기 로딩/부분 로딩/빈 검색/필터 결과 없음/결측/연결 끊김/복구/저장 실패를 구분한다. 결측은 0으로 대체하지 않는다. 내부 데이터에는 출처 추적, 기준 시각, 수집 시각, 단위, 기간, 집계 범위를 보존한다. 일반 화면에는 출처명, 원천 한도, 수집·갱신 시각을 표시하지 않고 지표 해석에 필요한 기간·단위만 보여준다. 실시간으로 표 값이 바뀌어도 순서는 고정하고 최신 순위 반영 동작으로 갱신한다. fixture는 별도 명시적 모드에서만 허용한다.

## 인터페이스
`/api/market/v1` REST 읽기와 조건 검색. 사용자 계정·개인정보 API는 두지 않으며, 관심종목과 저장 보기는 브라우저 로컬에 저장한다. `/api/market/v1/stream`은 수집기가 저장한 시세 스냅샷을 전달한다. 원천 수집은 별도 worker, API는 저장된 스냅샷을 읽는다.

## 완료 기준
360/390/768/1440px, 테마2종, 큰 글씨, 키보드, 뒤로 가기, 새로고침 후 복원. 시세는 장 상태와 실제 거래 자료를 구분해 표현하고, 확인할 수 없는 값은 빈칸으로 둔다. 일반 화면에 원천명·원천 한도·수집 또는 갱신 시각을 노출하지 않는다. 5명 사용성 조사는 사람 참여 전 미완료로 기록한다. API/배포/부하 측정은 각각 실제 결과를 기록한다.
