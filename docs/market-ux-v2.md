네이버의 공개 화면과 메뉴 구조를 확인했습니다. 로딩 중인 캡처를 완성된 차트 화면의 시각적 근거로 사용하지 않았습니다. 외부 서비스의 로고·고유 브랜드는 가져오지 않았고, 기업 로고는 시세 제공처가 반환하는 실제 로고 URL을 사용합니다.

## 핵심 흐름

1. 첫 화면에서 작은 지수 차트와 종목 순위를 함께 봅니다. 지수를 누르면 하루·1주·1개월·1년 상세 차트가 열립니다.
2. 거래대금·등락률·거래량·외국인 수급을 선택합니다. 수급 순위에서는 실제 수급 열을 표시합니다.
3. 종목명을 누르면 회사 로고·가격·차트·핵심 지표가 우선 나타납니다. 긴 회사 설명은 펼쳐 봅니다.
4. 재무·수급·공시는 탭에서 깊게 조회합니다. 설명·기간·원문 연결을 함께 제공합니다.
5. 누구나 바로 조회하며, 관심·보기는 로그인 없이 현재 기기에 저장합니다.

## 화면 구성과 상태

- 흰색/중립 회색 표면, 검은 선택 탭, 조작·초점에 절제된 파란색. 상승 빨강·하락 파랑을 부호와 함께 표시합니다.
- 큰 장식 영역을 줄이고 주요 가격과 기업명을 강조했습니다. 표는 숫자 오른쪽 정렬과 고정폭 숫자를 유지합니다.
- 모바일 기업 로고와 기업명을 한 줄 그룹으로 묶었습니다. 전체 표는 가로로 이동하고 모바일 기본 목록은 주요 숫자부터 보여줍니다.
- 지수 요약에는 장중/장 마감만 남기고, 공급사·수집 시각·갱신 주기 표시는 화면에서 뺐습니다. 종목의 재무 기간이나 공시일처럼 숫자 해석에 필요한 날짜는 유지합니다.
- 테마의 최초 로딩, 조회 실패, 빈 검색 결과를 구분하고 재시도 버튼을 제공합니다.
- 갱신 실패가 회복되면 오류 문구를 해제합니다. 네트워크 오류는 한국어로 안내합니다.

## 2026-09-25 탐색 마찰 보완

검색창을 비우고 열었을 때 서버 검색을 보내지 않고 최근 본 종목을 우선, 최근 기록이 없으면 현재 순위의 첫 종목을 추천합니다. 입력 검색은 15초 동안 결과를 기기 메모리에 캐시해 재검색 때 먼저 표시하고, 응답에는 검색 결과에 필요한 종목명·로고·가격·등락과 해당 숫자의 내부 출처 근거만 남깁니다. 검색·상세 API의 동기 데이터베이스 작업은 FastAPI의 기본 스레드 풀에서 처리하도록 바꿨습니다.

홈 순위에 시가총액을 추가하고 결과 개수와 전체 종목 이동 문구를 분리해, 상위 미리보기와 전체 종목 범위를 혼동하지 않게 했습니다. 이는 [네이버페이 증권의 국내 종목·순위 중심 탐색](https://m.stock.naver.com/domestic/stock/005930/total), [TradingView의 시가총액 기준 스크리너와 필드별 보기](https://www.tradingview.com/support/solutions/43000718866-tradingview-stock-screener-trade-smarter-not-harder/), [Simply Wall St의 시장·업종 드릴다운](https://support.simplywall.st/hc/en-us/articles/4406873032719--Getting-started-with-the-Market-and-Industry-Page)에서 확인한 탐색 원리를 이 서비스에 맞게 적용한 것입니다. 외부 서비스의 화면을 그대로 복제하지 않았습니다.

검증 기준은 빈 검색창을 열 때 검색 API 요청 0회, 시가총액 순위 선택 시 정렬·열·제목이 함께 전환, 같은 검색 재입력 시 기존 결과를 즉시 표시하는 것입니다. 이 검증은 브라우저 테스트와 검색 API 계약 테스트에서 확인합니다. 전체 시장 커버리지와 각 지표의 실제 제공 범위는 별도 데이터 감사 대상이며, 종목 수 표시를 지표별 데이터 완전성으로 해석하지 않습니다.

운영 배포 뒤 같은 검색어·같은 2개 종목을 비교했습니다. 전용 검색 응답은 6,947 UTF-8 bytes, 같은 조건의 전체 스크리너 응답은 33,981 bytes로 **79.6% 작아졌고**, 가격·등락 각각의 내부 근거도 남아 있습니다. 공개 HTTPS 검색과 시장 화면은 200을 반환했습니다. 서버 내부 반복 요청은 3.6–16.3ms였고, 첫 외부 요청은 네트워크를 포함해 2,696ms였습니다. 반복 내부 측정을 인터넷 이용자의 응답시간으로 일반화하지 않습니다.

검색 추천·시가총액 순위 화면 캡처: 검색창 즉시 추천 (로컬 보존 자료: `run-20260925-improvement/05-search-instant.png`). 브라우저 테스트 2개와 API 계약 테스트, TypeScript, 변경 파일 ESLint, 운영 빌드가 통과했습니다. 실제 사용자·중장년 사용성 평가는 아직 별도 검증입니다.
