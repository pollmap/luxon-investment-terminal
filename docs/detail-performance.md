# 종목 상세 성능 개선 검증 — 2026-09-26

상세 데이터 전체를 매초 다시 직렬화·압축하던 경로를 수정했다. 화면 기능과 숫자, 과거 가격 2,600행, 원문 추적 정보를 줄이지 않았다. 변경 전후 JSON 전체 일치를 확인했다.

## 측정 결과

최종 비교는 변경 전 상세 핸들러를 별도 로컬 프로세스에서 재현하여, 변경 후 API와 같은 저장 데이터를 읽게 했다. 브라우저 테스트를 끝낸 뒤 종목별 8회, 1.1초 간격으로 교대로 요청했다. 아래는 캐시를 준비한 뒤의 HTTP 응답 중앙값이다. 최초 실행·실제 휴대폰 렌더링·인터넷 지연·장중 데이터 갱신 부하는 포함하지 않는다.

| 종목 | 변경 전 전체 응답 | 변경 후 전체 응답 | 전체 응답 개선 | 변경 없는 재조회 | 재조회 개선 |
|---|---:|---:|---:|---:|---:|
| 삼성전자 | 22.58ms | 5.42ms | 4.16배 | 2.79ms | 8.08배 |
| SK하이닉스 | 18.79ms | 4.91ms | 3.83배 | 2.52ms | 7.45배 |
| 삼성전자우 | 13.95ms | 4.47ms | 3.12배 | 3.25ms | 4.29배 |

**10배 속도 목표는 아직 달성하지 못했다.** 전체 서비스나 최초 화면 로딩을 10배 빠르게 했다고 해석하면 안 된다. 초기 단독 측정과 최종 동시 비교의 절대 시간도 다르므로, 유리한 초기 수치를 최종 수치와 섞어 배율을 산출하지 않았다.

삼성전자 전체 응답의 압축 본문은 111,148 → 84,121바이트로 약 24% 줄었다. 변경 없는 재조회는 HTTP 304로 본문 0바이트이며 HTTP 헤더는 전송된다. 이 경우 브라우저의 JSON 재해석과 상세 데이터 교체도 생략한다. 별도의 5초 시세 조회는 유지한다.

## 변경 구조

- DB의 universe/enriched/quotes 및 종목별 detail/prices/collection/filings/official 수정 버전을 확인한다. 시간이 지난 것만으로 큰 응답을 다시 만들지 않는다.
- 같은 종목을 동시에 요청하면 응답 생성 작업을 공유한다. 압축 캐시는 LRU, 최대 128개·16MiB로 제한한다. 서로 다른 종목의 직렬화가 전체 시장 모델 잠금을 점유하지 않는다.
- DB 버전으로 판단하는 경로에서는 최대 2초 된 Redis 본문을 사용하지 않는다. 생성 중 원천 버전이 바뀌면 결과를 캐시에 등록하지 않는다.
- 브라우저는 현재 열린 상세 화면의 ETag 하나만 보관한다. 실패 시 마지막 화면을 유지하고 다음 갱신에서 복구한다. 종목을 떠나면 검증자는 폐기한다.
- 캐시 적중 여부와 무관하게 수집 요청은 기존 방식으로 유지한다. 저장된 원천의 갱신 주기를 바꾸거나 빠르다고 꾸미지 않는다.

## 검증

- 백엔드 관련 테스트 82개 통과. 종목 삭제, 8개 원천 변경, Redis 지연, 동시 요청, 메모리 상한, 압축 협상, 304와 새 데이터 응답을 포함한다.
- 브라우저 테스트 26개 통과. 360/390/768/1440px, 라이트·다크, 목록 복귀, 공매도·수급, 재조회 실패 후 복구를 포함한다.
- Next.js 운영 빌드, TypeScript 검사, 변경 프런트엔드 ESLint 통과.
- 최종 수치: `detail-performance-paired.json`. 초기 관측: `detail-performance-before.json`, `detail-performance-after.json`. 웹 프록시를 통한 후속 측정: `detail-performance-revalidation.json` (일부 구간에 브라우저 테스트 부하가 겹쳐 최종 배율에 사용하지 않음).

현재 구현을 다시 측정하려면 저장소 루트에서 다음을 실행한다.

```powershell
.venv\Scripts\python.exe scripts/benchmark_market_detail.py --base http://127.0.0.1:3216 --output work/detail-benchmark.json
```

로컬 운영 빌드는 `http://127.0.0.1:3216/stocks?code=005930`에 반영했다. 공개 서버 배포는 완료하지 않았다. 앞선 SSH 연결은 실행 환경의 네트워크 제한으로 차단되었으며 이번 로컬 개선을 공개 서버 반영으로 보고하지 않는다.
