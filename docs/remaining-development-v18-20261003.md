## 사용 경로

- 시세 → 선/영역/캔들/OHLC. 장기 차트에서 일·주·월봉과 기간을 선택한다.
- 시세 아래 ‘실적의 흐름’ 또는 기업 분석 → 재무에서 숫자와 전년 동기 증감률을 함께 읽는다.
- 기업 분석 → 재무 → ‘재무 보고 기간’에서 2015년 이후 보고서를 선택한다. 미수집 항목의 ‘조회’는 수집 요청이며 완료 표시가 아니다.
- 수급 → 투자자·프로그램에서 기간, 매수/매도/순매수, 기관 상세와 표를 선택한다.
- 공시·뉴스 → 공시/뉴스/리포트에서 해당 목록과 원문을 연다.
