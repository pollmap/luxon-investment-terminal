# Web Agent Rules

- Reference-first is mandatory for production UI changes. Inspect a captured
  FAST Graph-style source and the current LUXON implementation at the same
  viewport before material screen work. Existing Figma frames are archival
  inputs, while the checked-in Claude handoff and code are the active contract.
- Use LUXON tokens, existing terminal primitives, and source_trace UX patterns.
- Do not display production financial values without source_trace-aware data
  contracts and no-source states.
- Keep chart controls, forecast inputs, warnings, confidence, and Data Audit
  click-through visible and test-covered.
- Run `pnpm --filter @personal-fastgraphs/web exec tsc --noEmit` and relevant
  Playwright tests before commit.
